Kaggle-入门指南

介绍

Kaggle 是全球最大的数据科学与机器学习竞赛平台, 成立于 2010 年, 在 2017 年被 Google 收购. 其提供有很多免费课程可以学习, 而且每周有免费 GPU/TPU 额度, 可以配套其集成的数据集, 模型进行实战练习.

企业/机构会在 kaggle 上发布真实的预测问题作为竞赛, 参赛者通过提交预测结果取得分数和排名.

由于 “Kaggle” 和英文单词 “gaggle” (一群鹅) 长得很像, 所以 Kaggle 的默认头像/符号是一只鹅.

Kaggle Notebook

Kaggle notebook (以前称 kaggle kernel) 本质上是运行在浏览器里的 Jupyter notebook, 由 kaggle 平台免费提供. 配套有 GPU/TPU 资源可以用于模型训练.

如果别人有公开一个比赛的 notebook, 你也可以直接 fork 过来学习或者复现实验.

通常 notebook 所处环境是待机的状态, 在浏览器上可以查看 notebook 的内容. 如果运行了 notebook, 就会启动云端服务器:

  • 提供 4 核 CPU, 30GB 内存, 单次 Session 时间上限是 12 小时, 重启 session 能重置. 每周额度不限
  • 磁盘显示可用 57GB, 其中持久化磁盘目录是 /kaggle/working 只有约 20GB, 其余空间用来存放临时数据, 在 session 结束后会清空. 另外 /kaggle/input 是只读的, 用于存放挂载的数据集

  • GPU 可选 Tesla P100 16GB 或者两张 T4 (共 32GB), 每周额度 30 小时
  • TPU 可选 TPU v3-8, 每周额度 20 小时

Kaggle Environments

Kaggle Environments 分两种:

  • kaggle-environments Python 包, 其用作模拟类比赛的游戏环境库
  • gcr.io/kaggle-images/python:v163 Docker 镜像, 是 Kaggle 上 Notebook 运行的环境

如果只是要部署比赛环境, 通常装 pip 包即可. 如果是要自己搭建 Kaggle 那样的评测基础设施 (镜像中带有一些评测脚本), 比如多容器, agent 隔离评测等, 此时采用得到这个镜像.

kaggle-environments

这个库是官方微模拟/强化学习类比赛提供的库, 用来跑 episode 和评测 agent. 其内置了一堆现成的游戏环境, 比如 tictactoe, connectx 等等. 核心是 Gym 风格, 且 agent 被抽象为一个函数.

Kaggle Competition

奖牌规则

对于大型比赛 (1000+ 队伍报名), 获奖规则是:

  • Gold, 前 10 + 0.2% (5000 只队伍参加大约 20 枚)
  • Silver, 前 5% (5000 只队伍参加大约 250 枚)
  • Bronze, 前 10% (5000 只队伍参加大约 500 枚)

等级排行:

  • Contributor: 完成基本活跃 (提交 1 次, 跑一个 Notebook, 发 1 条评论)
  • Expert: 2 枚铜牌
  • Master: 1 金 + 2 银
  • GrandMaster: 5 金 (含至少 1 枚个人/队长金牌)

奖金规则由主办方定.

Kaggle 资源 handle

用后续要介绍的 kaggle-cli 或者 kagglehub 拉取 Kaggle 上的资源时, 使用的不是绝对 URL, 而是将 URL 中的一部分作为资源标识, 也叫 handle:

资源 Handle 格式 示例
Dataset owner/dataset unsdsn/world-happiness
Dataset 指定版本 owner/dataset/versions/N unsdsn/world-happiness/versions/1
Model owner/model/framework/variation google/bert/tensorFlow2/answer-equivalence-bem
Model 指定版本 owner/model/framework/variation/N google/bert/tensorFlow2/answer-equivalence-bem/1
Competition 比赛 slug digit-recognizer
Notebook 输出 owner/notebook alexisbcook/titanic-tutorial
Notebook 指定版本 owner/notebook/versions/N alexisbcook/titanic-tutorial/versions/1

Tips

阅读前排选手的 writeup 和 post, 看看别人怎么做的, 哪些方法可以迁移到别的比赛上.

特征工程很重要, 并不是所有 data 都是有用的, 需要学会分辨, 丢弃一些无用的数据. A good cross validation framework 很有用, 能用来辅助辨别这些特征.
