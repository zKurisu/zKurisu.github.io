Google-colab-基本使用

介绍

Google Colab (Google Colaboratory) 是 Google 免费提供的一个云端 Jupyter Notebook 环境, 可以直接在浏览器编写和运行 Python 代码. 其服务器环境中预装了 NumPy, Pandas, Matplotlib, scikit-learn, Tensorflow, PyTorch 等常用库, 并且提供免费的 CPU, 内存, 磁盘和 GPU 资源.

colab-cli

Colab CLI 是 Google 刚发布的开源工具, 作用是在终端创建和操控 GPU/TPU runtime. 适合跑脚本和给 AI Agent 当算力后端.
