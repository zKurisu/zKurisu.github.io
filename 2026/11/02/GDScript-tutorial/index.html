Array

数组是 Array 这个 class 的实例:

  • arr.append() 追加元素
  • arr.size() 获取长度
  • arr.shuffle() 打乱

Dictionary

常用方法有:

  • dict.empty() 判断是否为空
  • dict.has(key) 判断是否包含某 key
  • dict.has_all(list)
  • dict.get(key, error msg) 安全访问 key
  • dict.erase(key) 移出某 key
  • dict.keys()
  • dict.values()
  • dict.duplicate(true) deep copy
  • dict.duplicate() shallow copy

Class

  • class_name 声明一个全局类名, 会注册到 GDScript 的全局命名空间. GDScript 里的每个 .gd 文件本身就是一个隐式类, class_name 相当于给这个隐式类起了一个全局的名字
  • extends 指定父类
  • export 表示会序列化该成员, 便于外部编辑器直接修改 (可以直接在 Inspector 中变更, 修改后会覆盖脚本值, 但不会写入脚本), (String) 只是一个类型提示, 告诉编辑器使用哪种控件
