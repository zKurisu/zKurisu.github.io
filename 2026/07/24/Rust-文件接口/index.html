字符串转换

由于 Path 的本质是 [u8] 字节序, 没有 UTF-8 的先验假设 (就是你不知道这个字节序能不能解码成正常 UTF-8 字符), 即没有实现 Display, ToString 等 trait, 不能直接用 to_string() 方法进行转换.

需要先调用 to_string_lossy() 得到 Cow<'_, str>. 该函数的意思是, 如果路径是合法的 UTF-8, 则返回 Cow::Borrowed(&str) (零分配); 如果不是 UTF-8, 则会把非法字节替换成 � (U+FFFD), 返回 Cow::Owned(String) (这也是为什么叫 lossy, 相当于失真了).

然后 Cow<'_, str>.to_string() -> String 得到一个 String.
