Chapter 1: Basic Concepts

State, action, policy, …

用到的例子是 grid-world, 一个机器人在网格世界中移动, 每个 cell 有 Accessible/forbidden/target 其中一个属性, 且 world 存在 boundary:

强化学习中的 State 定义为: agent 在当前环境中的 status. 对应到 grid-world 中, 就是 agent 的 location, 对于复杂的问题, 可能还包括速度, 加速度, 温度等等信息:

将所有 state 集合到一起 (形成一个集合), 就是 State space: $S = \{s_i\}_{i = 1}^9$ (state 会影响 action 的选择, action 也会改变 state).

Action 就是在一个 state 下, 可以采取的行为, 比如:

  • $a_1$, 向上移动
  • $a_2$, 向下移动
  • …

一个 state 的所有可能 actions 构成 action space: $A(s_i) = \{a_i\}_{i=1}^5$.

需要注意 action space 是依赖于 state 的, 不同 state 下的 action space 不同.

采取一个 action 后, agent 从一个 state 移动到了另一个 state 的过程称为 State transition:

$$
\displaylines
{
\begin{aligned}
s1 \overset{a2}{\rightarrow} s2
\end{aligned}
}
$$

State transition 本质上定义了 agent 与环境的交互. 其可以用 tabular representation 来表现:

但只适用于 deterministic cases (一个 action 只可能进入一个 state).

对于 State transition 的更一般的表达是用 state transition probability, 用概率来描述 state transition. 比如下面例子, 描述在 $s_1$ 采用 action $a_2$ 回到 $s_2$:

$$
\displaylines
{
\begin{aligned}
p(s_2 | s_1, a_2) = 1 \newline \newline
p(s_1 | s_1, a_2) = 0, \forall i \ne 2
\end{aligned}
}
$$

该方式既能描述 deterministic case, 也能用于 stochastic cases.

Policy 会告诉 agent 在一个 state 下采取哪一个 action. 如果从示例上直观理解的话, 一个 policy 就表示一个箭头:

基于 policy 运行到底, 就能得到一个 path 或 trajectory:

Trajectory 通常用 $\tau$ 来表示, 表达式就是一个 state 和 action 的连续序列:

$$
\displaylines
{
\begin{aligned}
\tau = [(s_0, a_0), (s_1, a_1), …]
\end{aligned}
}
$$

如果一个 state 有两个可能的 action, 比如向下和向右, 那么向下进行到底能得到一个 trajectory, 向右进行到底能得到另一个 trajectory.

Policy 用 conditional probability 作为更一般的数学表示, 比如对 $s_1$ 有:

$$
\displaylines
{
\begin{aligned}
\pi (a_1 | s_1) = 0 \newline
\pi (a_2 | s_1) = 1 \newline
\pi (a_3 | s_1) = 0 \newline
\pi (a_4 | s_1) = 0 \newline
\pi (a_5 | s_1) = 0
\end{aligned}
}
$$

针对一个状态的所有概率之和应该等于 1. 上述描述的是一种 deterministic case; 如果是 stochastic case, 则会有多个概率不为 0.

也可以用 tabular representation 来表示 Policy, 该表示方法也是 general 的:

Reward, return, Markov decision process

Reward 是 RL 中一个独特的概念, 其本质是一个 real number, 每次采取一个 action 都会得到一个 reward:

  • 如果 reward 是 positive, 表明鼓励采取这种 action
  • 如果 reward 是 negative, 表明不希望采取这种 action, 相当于 punishment

Reward 通常被视为一种 human-machine interface, 即我们通过设计 reward 来与机器交互, 引导 agent 做出我们期望的行为.

比如在 grid-world 例子中可以设计:

  • 进入 forbidden area 时 $r_{forbid} = -1$
  • 进入 boundary 时 $r_{bound} = -1$
  • 到达 target 时 $r_{target} = 1$
  • 其余时候 $r = 0$

这样能引导 agent 走向目标区域. 同样可以用 tabular representation 来表示 reward transition, 但注意其只能表示 deterministic 的情况:

更 general 的方式也是 conditional probability, 比如:

  • $p(r = -1 | s_1,a_1) = 1$
  • $p(r \ne -1 | s_1,a_1) = 0$

对于 stochastic 的场景下, reward 本身是不确定的, 可能随环境改变.

Tranjectory 表示一个 state-action-reward chain (path), 比如:

对应的数学表示可以写为:

$$
\displaylines
{
\begin{aligned}
s_1 \overset{a_2}{\underset{r=0}{\rightarrow}} s_2 \overset{a_3}{\underset{r=0}{\rightarrow}} s_5 \overset{a_3}{\underset{r=0}{\rightarrow}} s_8 \overset{a_2}{\underset{r=1}{\rightarrow}} s_9
\end{aligned}
}
$$

可以看到其包含了 3 个部分: state, action 和 reward.

一个 trajectory 的 return 表示沿着该 trajectory 的所有 rewards 之和 (也可以说是 cumulative future reward), 比如对于上面例子有:
$$
\displaylines
{
\begin{aligned}
return = 0 + 0 + 0 + 1 = 1
\end{aligned}
}
$$

不同的 policy 会得到不同的 trajectory, 也会有不同的 return.

Return 可以用来衡量 policy 的好坏.

在上述例子中, 到达 target location 之后, 策略其实还在继续运行:

$$
\displaylines
{
\begin{aligned}
s_1 \overset{a_2}{\underset{r=0}{\rightarrow}} s_2 \overset{a_3}{\underset{r=0}{\rightarrow}} s_5 \overset{a_3}{\underset{r=0}{\rightarrow}} s_8 \overset{a_2}{\underset{r=1}{\rightarrow}} s_9 \overset{a_5}{\underset{r=1}{\rightarrow}} s_9 \overset{a_5}{\underset{r=1}{\rightarrow}} s_9 …
\end{aligned}
}
$$

此时的 return 就变为:

$$
\displaylines
{
\begin{aligned}
return = 0 + 0 + 0 + 1 + 1 + 1 + … = \infty
\end{aligned}
}
$$

解决的办法就是引入 discount rate $\gamma \in [0, 1)$, 得到 discounted return:

$$
\displaylines
{
\begin{aligned}
discounted\ return &= 0 + \gamma 0 + \gamma^2 0 + \gamma^3 1 + \gamma^4 1 + \gamma^5 1 + … = \newline \newline
&= \gamma (1 + \gamma + \gamma^2 + …) = \gamma^3 \frac{1}{1-\gamma}
\end{aligned}
}
$$

此时能得到一个有限解. 如果 $\gamma$ 接近 0, 那么 discounted return 就取决于更近未来 (near future, 越往后, $\gamma^n$ 越小, 后面项的影响就越小) 的 rewards; 而 $\gamma$ 接近 1 时, 其取决于更远未来 (far future, 衰减得慢, 积累起来的 reward 就会大一些) 得到的 return.

当 agent 沿着 policy 到达 terminal states, 得到的 trajectory 称为 episode (or a trial). 这种有限步的也被称为 episodic tasks.

有些任务没有 terminal states, 意味着其会永远与环境交互下去. 这类任务称为 continuing tasks.

通常会统一 episodic 和 continuing tasks, 有两种方法, 都是将 episodic task 转换为 continuing task:

  • 将 target state 视为 absorbing state, agent 进入该状态后, 任何 action 都是原地踏步留在该状态, 且后续的 reward 为 $r = 0$
  • 将 target state 视为普通的带 policy 的 state, 策略好的时候留在该状态; 不好时跳出

这里用的第二个方法.

Markov decision process (MDP)

MDP 是一个框架, 这里把上述提到过的概念都套在这里.

MDP 涉及几个 Sets:

  • State: 状态的集合, 就是 state space $S$
  • Action: action 的集合, 就是 action space $A(s), s \in S$
  • Reward: reward 的集合, $R(s, a)$

另一个要素是几个 probability distribution:

  • State transition probability: 在状态 $s$ 下, 采取 action $a$, 状态转移到 $s’$ 的概率 $p(s’|s,a)$
  • Reward probability: 在状态 $s$, 采取 action $a$, 得到的 reward $r$ 的概率 $p(r|s,a)$

第三个要素是 Policy: 在状态 $s$, 选择 action a 的概率是 $\pi (a|s)$.

最后 MDP 需要满足 Markov property, 也称 memoryless property, 即当前的概率与历史无关, 比如下面式子表明, 当前求 $p(s_{t+1}|a_{t+1}, s_t)$, 与 $a_1, s_0$, $a_2, s_1$ 这些历史状态无关:

$$
\displaylines
{
\begin{aligned}
p(s_{t+1} | a_{t+1}, s_t, …, a_1, s_0) = p(s_{t+1} | a_{t+1}, s_t) \newline \newline
p(r_{t+1} | a_{t+1}, s_t, …, a_1, s_0) = p(r_{t+1} | a_{t+1}, s_t)
\end{aligned}
}
$$

可以用 Markov decision process 这个名词来记忆上述组成:

  • Markov 对应 Markov property
  • decision 对应 policy
  • process 对应 sets 和 probability distribution

如果 policy 确定, 那么 markov decision process 就变成了 markov process.

Chapter 2: Bellman Equation

Why return is important

从之前的定义可以知道, return 是求一条 trajectory 上所有 reward 的累加, 其可以用来衡量一个 policy 的好坏 (设计的时候需要考虑清楚, 目标是让总的 reward 最大, 还是到达 ternimal state). 对于下图而言, return 的计算为:

首先要注意, $s_4$ 是循环箭头, 意思是停在当前状态, 此时 reward 还会累加, 是一个无穷等比数列.

$$
\displaylines
{
\begin{aligned}
v_\pi (s_4) = 1 + \gamma \cdot 1 + \gamma^2 \cdot 1 + …
\end{aligned}
}
$$

这里回顾一下等比数列求和公式, 设首项为 $a_1$, 公比为 $q$, 项数为 $n$:

  • 当 $q \ne 1$ 时:

$$
\displaylines
{
\begin{aligned}
S_n = a_1 \cdot \frac{1 - q^n}{1 - 1} = \frac{a_1 - a_n q}{1 - q}
\end{aligned}
}
$$

  • 当 $q = 1$ 时:

$$
\displaylines
{
\begin{aligned}
S_n = n a_1
\end{aligned}
}
$$

因此 $v_\pi (s_4)$ 计算为:

$$
\displaylines
{
\begin{aligned}
v_\pi (s_4) = 1 \cdot \frac{1 - \gamma^n}{1 - \gamma}
\end{aligned}
}
$$

由于 $\gamma \in [0,1]$, 当 $n \rightarrow \infty$ 时, $\gamma^n \rightarrow 0$, 因此:

$$
\displaylines
{
\begin{aligned}
v_\pi (s_4) = \frac{1}{1 - \gamma}
\end{aligned}
}
$$

从 $s_2$ 出发, 往下走到达 $s_4$, 及时奖励 $r = 1$, 后续在 $s_4$ 的 reward 是 $\gamma v_\pi (s_4)$:

$$
\displaylines
{
\begin{aligned}
v_\pi (s_2) = 1 + \gamma v_\pi (s_4) = 1 + \gamma \cdot \frac{1}{1 - \gamma} = \frac{1}{1 - \gamma}
\end{aligned}
}
$$

同理从 $s_3$ 出发, 往右走到达 $s_4$, 即时奖励 $r = 1$, 后续在 $s_4$ 的 reward 是 $\gamma v_\pi (s_4)$, 有:

$$
\displaylines
{
\begin{aligned}
v_\pi (s_2) = 1 + \gamma v_\pi (s_4) = 1 + \gamma \cdot \frac{1}{1 - \gamma} = \frac{1}{1 - \gamma}
\end{aligned}
}
$$

因此这里的 return 是:

$$
\displaylines
{
\begin{aligned}
v_\pi (s_1) &= 0.5 (1 + \gamma v_\pi (s_2)) + 0.5 (0 + \gamma v_\pi (s_3)) \newline \newline
&= 0.5 (-1 + \frac{\gamma}{1 - \gamma}) + 0.5 (\frac{\gamma}{1 - \gamma})
\end{aligned}
}
$$

本质是求从 1 开始向下和向右两个 policy 的期望值. 严格来说其不是 return 了, 而是后面要提到的 state value.

由于从每个 state 出发的 trajectory 都能得到一个 return, 比如下面例子:

假设从 s1 开始 policy 得到的 return 为 v1; 从 s2 开始得到的是 v2; s3 是 v3; s4 是 v4, 那么就有:

$$
\displaylines
{
\begin{aligned}
v1 = r_1 + \gamma v_2 \newline \newline
v2 = r_2 + \gamma v_3 \newline \newline
v3 = r_3 + \gamma v_4 \newline \newline
v4 = r_4 + \gamma v_1 \newline \newline
\end{aligned}
}
$$
这比较直观, s1 经一个 action 到 s2, 那么其 return 就是该 action 的 reward 加上 s2 的 return; 对于其他情况也是这个原理. 这种一个 state 的 return 依赖于其他 state 的 return 的 idea 在强化学习中被称为 Bootstrapping (Bootstrapping 原意是将两侧鞋带往上提的动作, 后引申出让自己原地腾空的讽刺意义, 而这里指代迭代自己得到结果的行为).

上述式子写成矩阵的形式就是:

简写为:
$$
\displaylines
{
\begin{aligned}
v = r + \gamma P v
\end{aligned}
}
$$

  • 这里的矩阵 $P$ 被称为状态转移概率矩阵, 用来连接 “当前状态” 与 “未来状态”, 比如从前面 4 组式子可以看出, $v_1 \rightarrow v_2$, 有即时奖励 $r_1$, 这里 $P$ 的第一行乘以 $v$ 向量, 得到的就是 $v_2$, 描述了这个状态转移过程
  • 如果环境中有 $N$ 个状态 (即状态空间的大小 $|S| = N$), 那么 $P$ 是一个 $N \times N$ 的方阵
  • $P$ 矩阵中位于第 $i$ 行, 第 $j$ 列的元素 $P_{i j}$ (通常记为 $P(s_j | s_i)$ 或 $P(s’ | s)$), 代表: 当 Agent 处于状态 $s_i$, 并且遵循策略 $\pi$ 时, 它在下一步转移到状态 $s_j$ 的概率
  • 从任何一个状态 $s_i$ 出发, 走向所有可能下一个状态的概率加起来必须等于 1, 所以矩阵 $P$ 的每一行元素之和都严格等于 1

这个式子就是该特定 deterministic 问题的 Bellman equation.

这个例子中最重要的点就是 bootstrapping 的 idea (这也是记忆 bellman equation 的一个诀窍, 等式左右都有 $v$), 一个 state 的 value 会依赖于其他 state 的 value. 还有就是用 matrix-vector form 来求解会比较容易.

将式子展开为针对某一个具体状态 $s_i$ 的标量形式为:

$$
\displaylines
{
\begin{aligned}
v(s_i) = r(s_i) + \gamma \sum_{s_j} P(s_j | s_i) v(s_j)
\end{aligned}
}
$$

State value

考虑一个 single-step process:
$$
\displaylines
{
\begin{aligned}
S_t \overset{A_t}{\rightarrow} R_{t + 1}, S_{t + 1}
\end{aligned}
}
$$

  • $t, t+1$ 都是离散的 time instances
  • $S_t$ 表示 t 时刻的 state
  • $A_t$ 表示 $S_t$ 采取的 action
  • $R_{t+1}$ 表示采取 $A_t$ 后得到的 reward
  • $S_{t+1}$ 表示采取 $A_t$ 后转移得到的 state

这里需要解释一下, 为什么 $S_t$ 对应的即时奖励会写成 $R_{t+1}$ 而非 $R_t$. 马尔可夫决策过程 (MDP) 在时间步 t 的交互顺序如下:

  1. 时刻 $t$ 开始: Agent 处于当前状态 $S_t$
  2. 做出决策: Agent 根据 $S_t$ 采取了动作 $A_t$
  3. 环境响应 (进入下一时刻): 环境接收到动作 $A_t$ 后, 发生状态转移和奖励计算
  4. 时刻 $t + 1$ 到来: 环境把两样东西交还给 Agent:
    • 新的状态: $S_{t+1}$
    • 即时奖励: $R_{t+1}$

这里的重点是: 虽然在 $t$ 时刻做出决策, 但是环境在 $t+1$ 时刻才会做出响应.

注意 $S_t, A_t, R_t$ 这些都是随机变量, 这里的每个操作都是用 probability distribution 来决定的:

  • $S_t \rightarrow A_t$, 一个 state 会采取什么样的 action, 由 $\pi(A_t = a | S_t = s)$ 决定
  • $S_t, A_t \rightarrow R_{t+1}$, 在一个 state 下采取一个 action, 会得到什么 reward, 由 $p(R_{t+1} = r | S_t = s, A_t = a)$ 决定
  • $S_t, A_t \rightarrow S_{t+1}$, 在一个 state 下采取一个 action, 会跳转到什么 state, 由 $p(S_{t+1} = s’ | S_t = s, A_t = a)$ 决定

当然可以把 single-step 扩展到 multi-step 的场景:

$$
\displaylines
{
\begin{aligned}
S_t \overset{A_t}{\rightarrow} R_{t+1},S_{t+1} \overset{A_{t+1}}{\rightarrow} R_{t+2},S_{t+2} \overset{A_{t+2}}{\rightarrow} R_{t+3},S_{t+3}
\end{aligned}
}
$$

将该 trajectory 上所有 reward 累加, 在附上 discounted rate, 就能得到 discounted return:

$$
\displaylines
{
\begin{aligned}
G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + …
\end{aligned}
}
$$

有了上述这些概念, 就能够定义 state value (state value function) 了, 其就是 $G_t$ 的期望值 (加权求和):

$$
\displaylines
{
\begin{aligned}
v_\pi (s) = E[G_t | S_t = s]
\end{aligned}
}
$$

  • 不同的 $s$ 能得到不同的 state value
  • 不同的 policy 会得到不同的 trajectory, 也会得到不同的 state value
  • $v_\pi (s)$ 也可以写为 $v(s, \pi)$

这里最好再列出几个式子, 才方便理解, 首先是 “期望” 的计算:
$$
\displaylines
{
\begin{aligned}
E[X] = \sum_x x \cdot P(x)
\end{aligned}
}
$$

注意这里的 $\sum_x$ 写法, 它的意思是遍历所有 x 的取值. 通常我们熟悉的写法是 $\sum_{x=1}^{10}$, 这种是手动指定了遍历的范围.

State value 的计算式还可以写成:
$$
\displaylines
{
\begin{aligned}
v_\pi (s) = E_\pi [G_t | S_t = s] \newline \newline
v_\pi (s) = \sum_\tau G(\tau) \cdot P(\tau | s,\pi)
\end{aligned}
}
$$

  • $\tau$ 是一条 trajectory
  • $P(\tau | s, \pi)$ 是这条 trajectory 出现的概率
  • $G(\tau)$ 是这条 trajectory 的 return

简单来说就是遍历当前 state 的所有 trajectory, 按照出现概率加权求和.

Bellman equation

Bellman equation 描述了不同 state 间 state value 的关系. 主要依赖的推导思想是: 当前 state 的 return 等于 immediate reward 加上下一个时刻的 return.

考虑一个 random trajectory:
$$
\displaylines
{
\begin{aligned}
S_t \overset{A_t}{\rightarrow} R_{t+1},S_{t+1} \overset{A_{t+1}}{\rightarrow} R_{t+2},S_{t+2} \overset{A_{t+2}}{\rightarrow} R_{t+3},S_{t+3}
\end{aligned}
}
$$

其 return $G_t$ 可以写为:
$$
\displaylines
{
\begin{aligned}
G_t &= R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + … \newline\newline
&= R_{t+1} + \gamma(R_{t+2} + \gamma R_{t+3} + …) \newline\newline
&= R_{t+1} + \gamma G_{t+1}
\end{aligned}
}
$$

写成 state value 的定义就有:
$$
\displaylines
{
\begin{aligned}
v_\pi (s) &= E[ G_t | S_t = s] \newline\newline
&= E[ R_{t+1} + \gamma G_{t+1} | S_t = s ] \newline\newline
&= E[ R_{t+1} | S_t = s ] + \gamma E[G_{t+1} | S_t = s]
\end{aligned}
}
$$

之后把两项都解出来就能得到 Bellman equation.

首先是 $E[R_{t+1} | S_t = s]$, 其等于在 $s$ 处采取所有可能的 action 后, 得到的 reward 的期望, 也就是 immediate reward 的 mean 值:

$$
\displaylines
{
\begin{aligned}
E[R_{t+1} | S_t = s] &= \sum_a \pi (a|s) E [R_{t+1} | S_t = s, A_t = a] \newline \newline
&= \sum_a \pi (a|s) \sum_r p(r | s, a) r
\end{aligned}
}
$$

  • $\pi (a|s)$ 是在 $s$ 处采取 action $a$ 的概率
  • 由于在 $s$ 处采取 $a$ 得到的 reward 也是一个概率分布, 因此需要求期望 $E [R_{t+1} | S_t = s, A_t = a]$
  • $p(r|s, a)$ 表示在 $s$ 处采取 $a$ 得到 reward $r$ 的概率. 这个可能不太符合直觉, 毕竟 state 和 action 都确定了, 按理说 reward 也是确定的. 事实上, 此时 reward 仍然可能是随机的, 因为在 MDP 的定义中, reward 本来就不是一个确定性函数, 下面是一个例子, 假设掷骰子走格子:
    • 状态 s: 你在格子 3
    • 动作 a: 掷骰子前进
    • 奖励 r: 取决于你落在哪里
    • 此时虽然 “掷骰子” 这个动作确定了, 但骰子本身是随机的, 因此 reward 随机

接下来展开第二项 $E[G_{t+1} | S_t = s]$, $G_{t+1}$ 是下一个 state 的 return, 因此会涉及到从 $s$ 到 $s’$ 的概率分布; 而从 $s$ 需要采取某个 action 才能到 $s’$, 因此涉及到从 $s$ 如何选取 action 的概率分布. 该项的本质是求 mean of future rewards:

$$
\displaylines
{
\begin{aligned}
E[G_{t+1} | S_t = s] &= \sum_{s’} E[G_{t+1} | S_{t+1} = s’] p(s’|s) \newline \newline
&= \sum_{s’} v_\pi (s’) p(s’|s) \newline \newline
&= \sum_{s’} v_\pi (s’) \sum_a p(s’ | s,a) \pi (a|s)
\end{aligned}
}
$$

完整的 Bellman equation 如下:

对状态空间中所有 state 列出上述公式, 然后进行求解, 这个过程也称作 policy evaluation, 因为其与 policy 相关.

这里的 $p(r | s,a)$ 和 $p(s’ | s,a)$ 代表 dynamic model.

总的来说, state value 语境下的 Bellman equation 就是: 当前 state 采取 action 得到的 reward 的期望, 加上 next state 的 state value.

Bellman equation: Matrix-vector form

先对上述 Bellman equation 做一个变换, 让整个式子看起来简化一些:

$$
\displaylines
{
\begin{aligned}
v_\pi (s) &= \sum_a \pi (a|s) [\sum_r p(r|s,a)r + \gamma \sum_{s’} p(s’|s,a) v_\pi (s’)] \newline \newline
v_\pi (s) &= r_\pi (s) + \gamma \sum_{s’} p_\pi (s’|s) v_\pi (s’) \newline \newline
其中: r_\pi (s) &\overset{\triangle}{=} \sum_a \pi (a|s) \sum_r p(r|s,a)r \newline \newline
p_\pi (s’|s) &\overset{\triangle}{=} \sum_a \pi (a|s) p(s’|s,a)
\end{aligned}
}
$$

为了写成 matrix-vector 的形式, 还需要为 state 标上号, 写为:

$$
\displaylines
{
\begin{aligned}
v_\pi (s_i) = r_\pi (s_i) + \gamma \sum_{s_j} p_\pi (s_j|s_i) v_\pi (s_j) \newline \newline
\end{aligned}
}
$$

写出所有 $s_i$ 的 bellman equation, 就得到矩阵形式:
$$
\displaylines
{
\begin{aligned}
v_\pi = r_\pi + \gamma P_\pi v_\pi
\end{aligned}
}
$$

  • $v_\pi = [v_\pi (s_1),…,v_\pi (s_n)]^T \in R^n$
  • $r_\pi = [r_\pi (s_1),…,r_\pi (s_n)]^T \in R^n$
  • $P_\pi \in R^{n \times n}$, $[P_{\pi}]_{i j} = p_\pi (s_j | s_i)$, 该矩阵也称 state transition matrix

下面是一个例子:

注意 $P_\pi$ 的一行乘以 $v_\pi$ 就恰好是 $\sum_{s_j} p_\pi (s_j|s_i) v_\pi (s_j)$.

解上述矩阵的过程就叫 “policy evaluation”.

其 closed-form solution 可以写为:

$$
\displaylines
{
\begin{aligned}
v_\pi = (I - \gamma P_\pi)^{-1} r_\pi
\end{aligned}
}
$$

但实际中一般不用这个求解, 因为维度高时, 求逆的计算量会比较大. 通常用 iterative solution, 这里还不太好理解这个式子, 它的语义与前述的 Bellman equation 有较大不同:

  • 之前的 Bellman equaition, 如果要计算第一个 state 的 state value, 那么要一直 “递” 到最后一个 state, 完成计算再 “归” 到第一个
  • 而这里可以直接算出第一个 state 的 state value, 此时右侧是瞎猜的估计值, 下面的 k 代表的也是迭代的轮数而非时序

$$
\displaylines
{
\begin{aligned}
v_{k+1} = r_\pi + \gamma P_\pi v_k
\end{aligned}
}
$$

  • 注意 $v$ 的下标是 $k$ 和 $k+1$, 与之前的 $\pi$ 并不冲突

这样一直得到一个序列 ${v_0, v_1, v_2,…}$, 我们可以证明, 当 $k \rightarrow \infty$ 时, $v_k$ 就收敛到了 $v_\pi$:

$$
\displaylines
{
\begin{aligned}
v_{k} \rightarrow v_\pi = (I - \gamma P_pi)^{-1} r_\pi, k \rightarrow \infty
\end{aligned}
}
$$

核心的证明思路是证明 $\delta_k = v_k - v_\pi$, 在 $k \rightarrow \infty$ 时, $\delta_k \rightarrow 0$.

Action value

这里说明下 state value 和 action value 的区别:

  • State value 是从一个 state 出发得到的 average return
  • Action value 是从一个 state 出发采取某个 action 后得到的 average return

Action 的选择通常就是根据 action value 来判断, 越大越容易选择. 其定义写为:

$$
\displaylines
{
\begin{aligned}
q_\pi (s,a) = E[G_t | S_t = s, A_t = a]
\end{aligned}
}
$$

  • 在 policy $\pi$ 下, 固定 state 和 action 得到的 return $G_t$ 的期望值

当然可以用 action value 来写 state value 的表达式:

同样, 如果知道了 state value, 也能用来求 action value:

$$
\displaylines
{
\begin{aligned}
q_\pi (s,a) = \sum_r p(r|s,a) r + \gamma \sum_{s’} p(s’|s,a) v_\pi (s’)
\end{aligned}
}
$$

Summary

几个关键概念和公式这里汇总下:

  • State value: $v_\pi (s) = E[G_t | S_t = s]$
  • Action value: $q_\pi (s, a) = E[G_t | S_t = s, A_t = a]$
  • The Bellman equation (elementwise form): $v_\pi (s) = \sum_a \pi (a|s) q_\pi (s,a)$
  • The Bellman equation (matrix-vector form): $v_\pi = r_\pi + \gamma P_\pi v_\pi$

不管是求 $v_\pi(s)$ 还是求 $q_\pi (s,a)$, 都称作 bellman equation.

Chapter 3: Bellman Optimality Equation

当当前策略不是最优时, 可以用 action value 来判断哪个 action 最优, 进而调整 policy:

$$
\displaylines
{
\begin{aligned}
\pi_{new} (a | s_1) =
\begin{cases}
1, a = a^* \newline \newline
0, a \ne a^*
\end{cases} \newline \newline
where\ a^* = argmax_a\ \ q_\pi (s_1, a)
\end{aligned}
}
$$

  • $a^*$ 表示最优的 action

用严格的数学工具说明上述过程的可靠性就是 Bellman Optimality Equation.

上面过程想表达的就是, 通过算 action value, 选出最大的那个, 然后调整策略为让该 action 的概率为 1.

Optimal policy

State value 可以用来衡量一个 policy 的好坏, 如果有:

$$
\displaylines
{
\begin{aligned}
v_{\pi_1} (s) \ge v_{\pi_2} (s) \ \ for\ all\ s\ in\ S
\end{aligned}
}
$$

即, 对任意状态都有 $\pi_1$ 带来的 state value 更大, 则说明 $\pi_1$ 比 $\pi_2$ 好.

因此正式的定义就是: 如果 policy $\pi^*$ 是 optimal, 那么就有 $v_{\pi^*} (s) \ge v_{\pi}(s)$, 对于任何 $s$ 或任何 policy $\pi$ 都成立.

Bellman optimality equation 定义如下 (elementwise form), 与 Bellman equation 的区别就是加上了 $\max_{\pi}$:

$$
\displaylines
{
\begin{aligned}
v(s) &= \max_{\pi} \sum_a \pi(a|s) (\sum_r p(r|s, a)r + \gamma \sum_{s’} p(s’|s,a)v(s’)),\ \forall s \in S \newline \newline
&= \max_{\pi} \sum_a \pi(a|s) q(s,a)\ \ s \in S
\end{aligned}
}
$$

(注意这里做了一个替换, 带入了 action value)

Matrix-vector form 如下 (同样只是在 Bellman equation 的基础上加上一个 max):

$$
\displaylines
{
\begin{aligned}
v = \max_{\pi} (r_\pi + \gamma P_\pi v) \newline \newline
[r_\pi]_s \overset{\nabla}{=} \sum_a \pi (a|s) \sum_r p(r|s,a) r \newline \newline
[P_\pi]_{s,s’} = p(s’|s) \overset{\nabla}{=} \sum_a \pi (a|s) \sum_s’ p(s’ | s,a)
\end{aligned}
}
$$

通常 $p(r|s,a)$ 和 $p(s’|s,a)$ 是已知的, 在给 $v(s’)$ 赋初始值之后, 整个 $q(s,a)$ 都是已知的.

求解 elementwise form, 其实就等价于 (下面等式右边, 就是让 $a^*$ 概率为 1, 其他 action 概率为 0, 相当于该 state value 就等于一个 action value):

$$
\displaylines
{
\begin{aligned}
\max_{\pi} \sum_a \pi(a|s) q(s,a) = \max_{a \in A(s)} q(s,a)
\end{aligned}
}
$$

也就是直接让最大的 $q(s,a)$ 的概率为 1:

$$
\displaylines
{
\begin{aligned}
\pi(a|s) =
\begin{cases}
1\ a = a^* \newline \newline
0\ a \ne a^* \newline \newline
where\ a^* = arg\ max_a q(s,a)
\end{cases}
\end{aligned}
}
$$

总结来说 (再重复一遍): Bellman Optimallity Equation 就是 Bellman equation 加上 $\max_a$, 目的是找到具有最大 $q(s,a)$ 的动作 $a^*$, 然后得到一个使 $\pi(a^*|s) = 1$ 的策略.

Contraction mapping theorem

这里引入 fixed point 的概念, 对于函数 $f: X \rightarrow X$, 如果有 $x \in X$:

$$
\displaylines
{
\begin{aligned}
f(x) = x
\end{aligned}
}
$$

就称 $x$ 是一个 fixed point.

如果一个 $f$ 是 contraction mapping (contraction function), 需要满足:

$$
\displaylines
{
\begin{aligned}
\vert \vert f(x_1) - f(x_2) \vert \vert \le \gamma \vert \vert x_1 - x_2 \vert \vert
\end{aligned}
}
$$

  • $\gamma \in (0,1)$, 也就是说映射后距离变短了

这里引出 Contraction Mapping Theorem: 对于任何 $x = f(x)$ ($x$ 通过一个以它为参数的函数求得) 这种形式的 equation, 如果 $f$ 是一个 contraction mapping, 那么就会有下面性质:

  • Existence: 存在一个 fixed point $x^*$, 满足 $f(x^*) = x^*$
  • Uniqueness: Fixed point $x^*$ 是 unique 的
  • Algorithm: 考虑序列 ${x_k}$, 且 $x_{k+1} = f(x_k)$, 那么当 $k \rightarrow \infty$ 时, 有 $x_k \rightarrow x^*$. 且 convergence rate 是指数级别的. 也就是说可以用迭代的方法找到 fixed point

对于 Bellman optimality equation, 可以写为:

$$
\displaylines
{
\begin{aligned}
v = f(v) = max_\pi (r_\pi + \gamma P_\pi v)
\end{aligned}
}
$$

其中可以证明 $f(v)$ 是 contraction mapping, $\gamma$ 是 discount rate. 那么我们就能通过迭代找到解.

假设 $v^*$ 是 Bellman Optimality equation 的解, 那么就满足:

$$
\displaylines
{
\begin{aligned}
v^* = \max_\pi (r_\pi + \gamma P_\pi v^*) \newline \newline
\pi^* = arg\ \max_\pi (r_\pi + \gamma P_\pi v^*) \newline \newline
v^* = r_{\pi^*} + \gamma P_{\pi^*} v^*
\end{aligned}
}
$$

可以看出, Bellman Optimality equation 其实就是一种特殊的 Bellman equation, 只不过采取 $\pi^*$ 最优策略, 得到的也是最优 state value $v^*$. 其实就是采取让 $a^*$ 概率最大的策略的 Bellman equation.

这里需要理解 $v^*$ 表示的含义: 其并不是代表某一个具体的终局状态, 而是一个函数, 它给每一个可能的状态都赋了一个数值, 表示 “从那个状态出发, 按最优策略走, 你能拿到的期望总回报是多少”.

比如对于一个德州扑克游戏, 状态 $s$ 表示:

  • 你的手牌: $A, K$
  • 公共牌: $Q, J$
  • 对手下注: 100 筹码

此时 $v*(s)$ 就表示, 将状态 $s$ 喂给函数 $v^*$, 得到从这一手牌出发, 按最优策略 (什么时候加注, 什么时候弃牌, 什么时候跟注) 玩下去, 你期望赢多少筹码.

Analyzing optimal policies

影响 optimal policy ($\pi(a|s)$) 决策的主要有 3 个 factors:

  • Reward design: $r$
  • System model: $p(r|s,a), p(s’|s,a)$
  • Discount rate: $\gamma$

通常调整 $r$ 和 $\gamma$ 是比较容易的.

Chapter 4 Value Iteration & Policy Iteration

Value iteration 和 policy iteration 都是为了得到 $v^*$ 这个函数, 相当于是得到包含每个 state 出发拿到最大收益的映射表. Policy iteration 还额外维护了 $\pi^*$.

Value Iteration algorithm

Value iteration 就是随机化 $v_0$, 算出一个固定值 $\pi_k$, 然后不断迭代到 $v^*$. Policy iteration 就是随机化 $\pi_0$ 和 $v_0$, 算出一个固定值 $v_{\pi_k}$, 然后不断迭代到 $\pi^*$.

$$
\displaylines
{
\begin{aligned}
v_{k+1} = f(v_k) = \max_\pi (r_\pi + \gamma P_\pi v_k), k= 1,2,3…
\end{aligned}
}
$$

这个算法其实叫做 “value iteration”.

需要注意这里的下标, $k$ 表示的不是 “时间步”, 而是 “迭代次数”:

  • $v_k$ 表示当前手里的 “旧的, 不太准确的” 价值表
  • $v_{k+1}$ 表示经过一次 Bellman 算子作用后, “更新的, 更准一点的” 价值表

(想象弹簧是从 $v^*$ 向 $v_0$ 出发的, 随着迭代次数增加, 弹簧不断收缩, 直到不动点)

该式子分两步计算, 会给定一个初始的 $v_0$:

  1. Policy update, 先找到最优的 $\pi$

$$
\displaylines
{
\begin{aligned}
\pi_{k+1} = arg\ max_\pi (r_\pi + \gamma P_\pi v_k)
\end{aligned}
}
$$

  1. Value update, 用找到的 $\pi$ 更新 value

$$
\displaylines
{
\begin{aligned}
v_{k+1} = r_{\pi_{k+1}} + \gamma P_{\pi_{k+1}} v_k
\end{aligned}
}
$$

Policy iteration algorithm

给定一个 random initial policy $\pi_0$, 然后分两步迭代:

  1. Policy evaluation (PE), 计算在 $\pi_k$ 下的 state value:

$$
\displaylines
{
\begin{aligned}
v_{\pi_k} = r_{\pi_k} + \gamma P_{\pi_k} v_{\pi_k}
\end{aligned}
}
$$

  1. Policy improvement (PI), 更新成新的 policy $\pi_{k+1}$:

$$
\displaylines
{
\begin{aligned}
\pi_{k+1} = arg\ \max_{\pi’ \in \Pi} (r_{\pi’} + \gamma P_{\pi’} v_{\pi_k})
\end{aligned}
}
$$

这里 $\Pi$ 是所有可能的策略集合, $\pi’$ 是遍历变量, $v_{\pi_k}$ 是第一步算出来的固定值.

整个过程如下:

$$
\displaylines
{
\begin{aligned}
\pi_0 \overset{PE}{\rightarrow} v_{\pi_0} \overset{PI}{\rightarrow} \pi_1 \overset{PE}{\rightarrow} v_{\pi_1} \overset{PI}{\rightarrow} \pi_2 \overset{PE}{\rightarrow} v_{\pi_2} …
\end{aligned}
}
$$

每次迭代一定有:

$$
\displaylines
{
\begin{aligned}
v_{\pi_0} \le v_{\pi_1} \le v_{\pi_2} \le … \le v^*
\end{aligned}
}
$$

Chapter 5: Monte Carlo Learning

Monte Carlo Learning 是一种 model-free 的方法. Model-based 方法就是指借助概率模型的方法, 比如 Transformer 其实就可以视作一个概率模型, 以一个概率输出 token.

对于 Model-based 方法, 都假设 probabilistic model 是已知的, 比如扔硬币, X=1 表示正面朝上, 概率是 0.5, X=-1 表示反面朝上, 概率也是 0.5, 那么 Expectation 的计算就是: $E[X] = 0.5 \times (-1) + 0.5 \times 1 = 0$.

Monte Carlo 的思想是用频率近似概率, 在上述例子中, 扔无数次硬币, 可以发现接近一半是正面朝上, 另一半反面朝上, Expectation 的计算为: $E[X] \approx \frac{1}{N} \sum X$.

大数定理 (Law of Large Numbers): 对于一个随机变量 $X$, 假设 $\{x_j\}j^N$ 是一些 independent and identically distributed sample, 且 $\overline{x} = \frac{1}{N} \sum{j = 1}^N x_j$ 是这些样本的平均值. 则有:

$$
\displaylines
{
\begin{aligned}
E[\overline{x}] = E[X] \newline \newline
Var[\overline{x}] = \frac{1}{N} Var[X]
\end{aligned}
}
$$

结果可以证明, $\overline{x}$ 是 $E[X]$ 的 unbiased estimate, 当 N 趋于无穷时, 其 variance 趋于 0. 大数定理想回答的问题就是: “用样本均值去估计整体真实均值, 会不会系统性地偏高或偏低”, 得到 $E[\overline{x}] = E[X]$, 则说明没有系统性误差.

要理解上面内容, 需要先补充下面知识.

首先是 identically distributed (同分布), 可以把 $\sum_{j=1}^N E[x_j]$ 拆开看:

$$
\displaylines
{
\begin{aligned}
\sum_{j=1}^N E[x_j] = E[x_1] + E[x_2] + E[x_3] + … + E[x_N]
\end{aligned}
}
$$

其中每一个样本 $x_j$ 都是从同一个总体 $X$ 中独立同分布抽取出来的, “同分布” 意味着每一个具体抽出来的样本 $x_j$, 它们背后的概率分布和原始变量 $X$ 是完全一模一样的. 这里需要注意 $x_1$ 也是一个随机变量, 它表示第一次抽样的结果, 但还没有开始抽, 并不是一个具体值.

既然概率分布一样, 那么它们的期望自然也是一样的, 即:

$$
\displaylines
{
\begin{aligned}
E[x_1] = E[X] \newline \newline
E[x_2] = E[X] \newline \newline
…
\end{aligned}
}
$$

$x_1$, $x_2$ 这种本质上就是 $X$, 只不过带上了 “第一次抽取”, “第二次抽取” 这种语义.

由于期望计算中常数是可以提出来的, 因此计算 $\overline{x}$ 的期望可以写为:

$$
\displaylines
{
\begin{aligned}
E[\overline{x}] &= E[\frac{1}{N} \sum_{j=1}^N x_j] \newline \newline
&= \frac{1}{N} \sum_{j=1}^N E[x_j] \newline \newline
&= \frac{1}{N} \cdot N \cdot E[X] = E[X]
\end{aligned}
}
$$

Variance (方差) 衡量的是, 一个随机变量的取值, 围绕其 Expectation 的 “波动程度”:

  • 方差大, 即数值经常大幅偏离均值
  • 方差小, 即数值很稳定, 集中在均值附近
    $$
    \displaylines
    {
    \begin{aligned}
    Var(Y) = E[(Y - E[Y])^2]
    \end{aligned}
    }
    $$

这里 $\overline{x}$ 的 Variance 计算为:
$$
\displaylines
{
\begin{aligned}
Var(\frac{1}{N}\sum_{j = 1}^N x_j) &= \frac{1}{N^2} \cdot \sum_{j=1}^N Var(x_j) \newline \newline
&= \frac{1}{N^2} \cdot N \cdot Var(X) \newline \newline
&= \frac{1}{N} Var(X)
\end{aligned}
}
$$

意思是方差会随样本增加而衰减, 即抽取并记录的样本量 N 越大, $\overline{x}$ 的波动就越小.

Unbiased Estimate (无偏估计) 意味着没有系统性偏差, 当一个估计量 (这里是 $\overline{x}$) 的期望值恰好等于你想估计的真实参数时 (这里的总体均值是 $E[X]$), 它就是无偏估计 (即 $E[\overline{x}] = E[X]$).

这里之所以会着重提到 Expectation, 是因为 state value 和 action value 的定义也是 expectations of random variables:

  • $v_\pi(s) = E[G_t | S_t = s]$, 即一个 state 的所有 trajectory 的 return 的 expectations
  • $q(s, a) = E[G_t | S_t = s, A_t = a]$, 即一个 state 在做某个 action 后的所有 trajectory 的 return 的 expectations

MC Basic

这一节的核心思想是把 policy iteration 中的 model-based 部分替换为 model-free 的.

首先 policy iteration 在每次迭代时分两步:

  • Policy evaluation: $v_{\pi_k} = r_{\pi_k} + \gamma P_{\pi_k} v_{\pi_k}$
  • Policy improvement: $\pi_{k + 1} = argmax_\pi (r_\pi + \gamma P_\pi v_{\pi_k}$

Policy improvement 写成下面形式更好理解:

$$
\displaylines
{
\begin{aligned}
\pi_{k+1} (x) = argmax_\pi \ \sum_a \pi(a | s) q_{\pi_k} (s, a),\ s \in S
\end{aligned}
}
$$

这里 action value 有两种计算方法:

  • 基于 model 的:

$$
\displaylines
{
\begin{aligned}
q_{\pi_k} (s, a) = \sum_r p(r | s,a) r + \gamma \sum_{s’} p(s’ | s, a) v_{\pi_k} (s’)
\end{aligned}
}
$$

  • 不依赖 model 的, 用最原始的定义计算:

$$
\displaylines
{
\begin{aligned}
q_{\pi_k} (s,a) = E[ G_t | S_t = s, A_t = a]
\end{aligned}
}
$$

因此 model-free RL 的核心就是用第二种 $q_{\pi_k} (s,a)$ 的计算方法替换第一种计算.

具体来说明, 假设我们从 $(s, a)$ 出发, 由 policy $\pi_k$, 得到一个 episode, 其 return 为 $g(s, a)$. $g(s, a)$ 本质是 $G_t$ 的一个 sample:

$$
\displaylines
{
\begin{aligned}
q_{\pi_k} (s,a) = E[ G_t | S_t = s, A_t = a]
\end{aligned}
}
$$

假设我们得到了一组 episodes $\{g^{(j)} (s, a)\}$, 则有:

$$
\displaylines
{
\begin{aligned}
q_{\pi_k} (s,a) = E[ G_t | S_t = s, A_t = a] \approx \frac{1}{N} \sum_{i=1}{N} g^{(i)} (s,a)
\end{aligned}
}
$$

当没有 model, 需要 model-free 的方法时, 就需要大量的 sample data, 而这些 data 在 RL 领域称作 experience.

MC epsilon-Greedy

MC epsilon-Greedy 通过引入 soft policy 来去掉 Exploring starts 这个条件.

首先需要理解 deterministic policy, stochastic policy 这两个概念.

强化学习中的 policy 本质上是一个从状态空间到动作空间的映射函数.

Deterministic policy (确定性策略) 会将状态映射到一个唯一的动作:

$$
\displaylines
{
\begin{aligned}
\mu : S \rightarrow A
\end{aligned}
}
$$

特点是无随机性, 只要输入同一个状态 $s$, 智能体必定做出完全相同的动作 $a$.

Stochastic policy (随机性策略) 将状态映射到动作空间上的概率分布.

$$
\displaylines
{
\begin{aligned}
\pi(a|s) = P(A_t = a | S_t = s)
\end{aligned}
}
$$

输入状态 $s$, 策略返回在当前状态下采取各个动作 $a$ 的条件概率, 智能体会通过对该分布进行采样来决定最终动作. 特点就是自带探索能力, 在相同状态下, 智能体也有机会尝试不同的动作.

这里的 $\epsilon$-greedy policy 就是一种 stochastic policy.

$$
\displaylines
{
\begin{aligned}
\pi_{k+1} (a | s) = \begin{cases}
1 - \frac{|A(s)| - 1}{|A(s)|} \epsilon, for\ the\ greedy\ action \newline \newline
\frac{\epsilon}{|A(s)|}, for\ the\ other\ |A(s)| - 1\ actions
\end{cases}
\end{aligned}
}
$$

  • Greedy action 就是指 action value 最大的那个 action
  • $\epsilon \in [0,1]$
  • $|A(s)|$ 表示 $s$ 处的 actions 数

上述公式是这样来的: 由于有 $|A(s)| - 1$ 个 non-greedy action, 因此它们的概率概率之和为: $\frac{|A(s)| - 1}{|A(s)|} \epsilon$, 剩下的概率都归 greedy action, 也就是 $1 - \frac{|A(s)| - 1}{|A(s)|} \epsilon$.

主要目的是通过 $\epsilon$ 给其他 non-greedy action 一个能够被选择的小概率.

由于从一个 $(s, a)$ 出发, 都可能到达其他所有 $(s, a)$ pair, 因此不需要 exploring starts 这个遍历条件了, 可以在一个长的 trajectory 中访问到所有的 $(s, a)$ pair.

比如下面例子, 当 $\epsilon$ 是一个非零值时, 一个短的 episode (比如这里的 100 steps 和 1000 steps), 并没有访问到所有的 $(s, a)$ pair, 但当 episode 很长时 (比如这里的 10000 steps), 就能访问到所有 $(s, a)$ pair 了:

$\epsilon$-greedy 主要是在 exploitation 和 exploration 之间做平衡:

  • Exploitation 就是指选取 action value 最高的 action, 即 greedy action
  • Exploration 就是指取 non-greedy action

当 $\epsilon = 1$, 相当于 action space 是一个均匀分布, 所有 action 被选取的概率相同.

简单来说, $\epsilon$-greedy policy 就是给所有 non-greedy action 提供了 $\frac{1}{|A(s)|} \epsilon$ 的概率, 剩下概率给 greedy action, 而非 greedy action 的概率为 1. 这种方式能够让 agent 有机会访问到所有的 $(s, a)$ pair, 因此不需要 exploring starts 的低效遍历.

$\epsilon$-greedy policy 的探索性比较强, 但是会牺牲最优性.

Chapter 6: Stochastic Approximation and Stochastic Gradient Descent

计算 mean $\overline{x}$ 时存在一个问题, 就是需要等所有样本采样完成, 才能够计算出, 也就是需要等待:

$$
\displaylines
{
\begin{aligned}
E[X] \approx \overline{x} := \frac{1}{N} \sum_{i=1}^N x_i
\end{aligned}
}
$$

如果采用 incremental 和 iterative 的计算方式能避免这种等待, 即来几个数据就先算几个, 公式推导如下.

对于前 k 个样本的 expectation 计算有:

$$
\displaylines
{
\begin{aligned}
w_{k+1} = \frac{1}{k} \sum_{i=1}^k x_i,\ \ k=1,2,…
\end{aligned}
}
$$

对于前 $k-1$ 个样本的 expectation 计算有:

$$
\displaylines
{
\begin{aligned}
w_{k} = \frac{1}{k-1} \sum_{i=1}^{k-1} x_i,\ \ k=2,3,…
\end{aligned}
}
$$

将 $w_{k+1}$ 用 $w_k$ 表示:

$$
\displaylines
{
\begin{aligned}
w_{k+1} &= \frac{1}{k} \sum_{i=1}^k x_i \newline \newline
&= \frac{1}{k} ( \sum_{i=1}^{k-1} x_i + x_k ) \newline \newline
&= \frac{1}{k} ( (k-1)w_k + x_k ) \newline \newline
&= w_k - \frac{1}{k}(w_k - x_k)
\end{aligned}
}
$$

这就是迭代写法的公式.

更 general 的形式是把系数 $\frac{1}{k}$ 写成 $\alpha_k$:

$$
\displaylines
{
\begin{aligned}
w_{k+1} = w_k - \alpha_k(w_k - x_k)
\end{aligned}
}
$$
当 $\alpha_k$ 不等于 $\frac{1}{k}$ 时, 也能够逼近 $E[x]$.

该算法是一种特殊的 stochastic approximation algorithm, 也是特殊的 stochastic gradient descent algorithm.

Stochastic approximation (随机逼近算法, SA) 是一类用于在含有噪声, 不完全信息或无法直接观测精确数学模型的环境下, 求解方程根或最优化问题的迭代算法. 基于这个定义, 也可以理解为什么 $w_{k+1} = w_k - a_k (w_k - x_k)$ 是一种特殊的 SA 算法了: 首先没有具体的 $w_k$ (这里是期望) 的公式, 另外也基于迭代.

  • Stochastic 指输入数据, 测量过程或环境反馈中包含随机噪声. 比如 $w_1$ 是随机取的初始值, $x_k$ 是随机变量的一个观测值 (每次取都会有波动), 整个过程受随机性支配
  • Approximation 指算法无法在有限步内一步到位得到精确解, 而是通过不断的迭代, 让估计值逐步 “逼近” 真实目标

随着观测步长越来越大, $\frac{1}{k}$ 会越来越小. 当 $k \rightarrow \infty$ 时, 式子近似变为 $w_{k+1} = w_k$ (后面那项趋于 0).

Stochastic approximation 的概念是由 Herbert Robbins 和 Sutton Monro 于 1951 年首次提出的. 在科学计算和工程中都很常用, 因为:

  1. 真实期望/积分往往无法直接计算, 比如优化目标中包含期望 $min_w E[f(w,X)]$, 在高维或复杂场景下, 如果要用全样本求和, 计算量会非常庞大. 或者概率分布本身就是未知的, 此时只能用样本估计
  2. 数据是流式的 (streaming), 数据源源不断产生, 而不是把所有历史数据全部存下来批量处理
  3. 传统数值优化方法失效, 比如牛顿法或梯度下降需要精确的梯度值, 在噪声环境下, 如果直接把梯度当作确定性数值来计算, 算法会彻底失效

Gradient

这里再重新理解一下 Gradient, 需要注意这部分并不是课程内容.

在单变量的微积分中, 给定一个函数 $f(x)$, 导数 $f’(x)$ (或 $\frac{df}{dx}$) 表示的是:

  • 几何意义: 函数曲线在某一点的切线斜率
  • 物理意义: 当自变量 $x$ 发生微小变化时, $f(x)$ 变化的快慢

对于二元函数比如 $f(x,y)$ (本质就是 3 维的图, 毕竟是 $z = f(x,y)$ 有 3 个变量), 可以想象成一个地形图, 在某个具体的位置 $(x_0, y_0)$, 如果沿 $x$ 轴正方向走一步, 海拔会如何变化? 如果沿 $y$ 轴正方向走一步, 海拔又如何变化? 如果沿任意方向移动, 海拔变化最快的是哪个方向?

这里就引入了偏导数和梯度的概念.

偏导数就是对于一个多元函数, 如果想查看一个维度的变化率, 那么可以固定其他变量, 将其视为常量, 然后求导:

  • 对 $x$ 的偏导数记为 $\frac{\partial f}{\partial x}$. 比如 $f(x,y)$ 中把 $y$ 视为常数, 只看 $f(x,y)$ 随 $x$ 变化的导数. 它代表了沿着平行于 x 轴方向的切线斜率
  • 对 $y$ 的偏导数记为 $\frac{\partial f}{\partial y}$. 比如 $f(x,y)$ 中把 $x$ 视为常数, 只看 $f(x,y)$ 随 $y$ 变化的导数. 它代表了沿着平行于 y 轴方向的切线斜率

偏导数只能告诉沿着 x 轴, 或沿着 y 轴这种 “正东方向”, “正北方向” 的陡峭程度, 而如果想要求 “东北偏东 30 度方向” 的呢? 此时就需要方向导数.

假设我们在点 $(x_0, y_0)$ 处, 想要沿着一个单位向量 $v = (v_1, v_2)$ 的方向 (满足 $v_1^2 + v_2^2 = 1$) 前进一小步微小的距离 $h$.

根据全微分公式, 函数值的变化量 $\delta f$ 可以近似表示为:
$$
\displaylines
{
\begin{aligned}
\delta f \approx \frac{\partial f}{\partial x} \cdot (h v_1) + \frac{\partial f}{\partial y} \cdot (h v_2)
\end{aligned}
}
$$

  • $h v_1$ 算出在 x 上的变化
  • $h v_2$ 算出在 y 上的变化

此时用函数的变化量除以步长 $h$, 就能得到沿方向 $v$ 的方向导数 (directional derivative):

$$
\displaylines
{
\begin{aligned}
D_v f = \lim_{h \rightarrow 0} \frac{f(x_0 + h v_1, y_0 + h v_2) - f(x_0, y_0)}{h} = \frac{\partial f}{\partial x} v_1 + \frac{\partial f}{\partial y} v_2
\end{aligned}
}
$$

直观看起来就是所有变量的 partial derivative 各自乘上方向向量.

上述式子还能写出内积形式:

$$
\displaylines
{
\begin{aligned}
D_v f = \begin{bmatrix}
\frac{\partial f}{\partial x} \newline \newline
\frac{\partial f}{\partial y} \newline \newline
\end{bmatrix} \cdot
\begin{bmatrix}
v_1 \newline \newline
v_2 \newline \newline
\end{bmatrix}
\end{aligned}
}
$$

其中偏导数部分的向量就是 gradient (梯度向量, 简单来说就是各变量的偏导组成的向量), 记作 $\nabla f$:

$$
\displaylines
{
\begin{aligned}
\nabla f(x,y) = (\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y})
\end{aligned}
}
$$

因此方向向量 $D_v f$ 又可以写为:

$$
\displaylines
{
\begin{aligned}
D_v f = \nabla f \cdot v = || \nabla f || \cdot || v || cos \theta
\end{aligned}
}
$$

从上面式子可以看出, 梯度 $\nabla f$ 相当于是 $|| v || cos \theta$ 为 1 时的方向向量, 也就是说: 梯度是最大的方向向量.

因此这里也能看出梯度的重要性, 梯度就是函数变化最快的方向.

Robbins-Monro algorithm

Stochastic approximation (SA) 指代一类算法, 用来方程求解或者优化问题求解.

Robbins-Monro algorithm 是 SA 领域中非常具有开创性的一个工作. 我们熟知的 stochastic gradient descent algorithm 就是 RM algorithm 的一种特殊形式 (前面介绍的 mean estimation algorithms 也是一种特殊的 RM 算法).

如果说 Stochastic Approximation 提供了一种 “在噪声环境中摸着石头过河” 的直觉和算法框架, 那么 Robbins-Monro 理论就是为这个框架提供的数学保证.

Robbins-Monro 回答了为什么 SA 可以做成, 以及需要什么条件才能成功.

比如之前迭代求期望的 $w_{k+1} = w_k - a_k (w_k - x_k)$, 需要面临一个问题: 每次拿到的 $x_k$ 都带有随机误差, 凭什么 $w_k$ 一定会收敛到真实的期望或者根上呢? 会不会因为噪声太大而发散? 或者永远在一个区间里无规律地震荡?

在 1951 年之前, 数学界并没有严格的证明来保证这种含噪声的迭代过程是收敛的. Herbert Robbins 和 Sutton Monro 第一次用严谨的概率论语言, 给出了算法收敛的数学证明. 其最核心的贡献, 就是在数学上证明了: 步长 $a_k$ (比如之前的 $\frac{1}{k}$) 必须满足两个极为苛刻的数学条件, 算法才能收敛.

Robbins-Monro 条件如下:

  1. $\sum_{k=1}^\infty a_k = \infty$ (累加发散). 步长的总和必须是无穷大, 确保 $k$ 在增长时, 步长 $a_k$ 不会衰减太快, 导致算法还没走到终点, 步子就已经小到等于零了, 导致永远走不到真实解
  2. $\sum_{k=1}^\infty a_k^2 < \infty$ (平方累加收敛). 步长的平方和必须是有限的, 随着时间推移, 算法最终能够收敛才行, 不能反复震荡

这里引入的问题是求解下面方程的解:

$$
\displaylines
{
\begin{aligned}
g(w) = 0
\end{aligned}
}
$$
$w \in R$ 是要求解的变量, $g$ 是 $R \rightarrow R$ 的函数.

很多问题都可以转换为上述求解过程, 比如求 $J(w)$ 的一个极值, 本质上就是:
$$
\displaylines
{
\begin{aligned}
g(w) = \nabla_w J(w) = 0
\end{aligned}
}
$$

对于 $g(w) = c$ 这种形式, 也可以转换: $g(w) - c = 0$.

这里我们要求解的是 $g(w)$ 本身表达式不知道的情况 (已知表达式就能用一些特殊算法求解了). 可以把神经网络看作是 $y = g(w)$, w 就是网络的参数.

既然缺少表达式, 我们就需要更多借助数据.

Robbins-Monro 是一个迭代式的算法:
$$
\displaylines
{
\begin{aligned}
w_{k+1} = w_k - a_k \overset{\sim}{g} (w_k, \eta_k)
\end{aligned}
}
$$

  • $w_k$ 是迭代了 k 次的解
  • $a_k$ 是一个常数系数 (正数)
  • $\overset{\sim}{g} (w_k, \eta_k) = g(w_k) + \eta_k$ 是第 k 次迭代的观察到的噪音

这里把 $g(w)$ 当作一个黑盒:

  • 输入序列是 $\{w_k\}$
  • 输出序列是 $\{\overset{\sim}{g} (w_k, \eta_k)\}$

迭代 k 次, 就能得到输入和输出序列:

RM theorem 描述如下:

当 3 个条件满足了, 那么 $w_k$ 就能收敛到 $w^*$, 其中 $g(w^*) = 0$.

解释一下这里的 3 个 conditions:

  • $0 < c_1 \le \nabla_w g(w) \le c_2$ for all w,
    • $0 < c_1 \le \nabla_w g(w)$ 意味着 $g$ 需要是单调递增 (monotonically increasing), 保证 $g(w) = 0$ 的解一定存在且唯一
    • $\nabla_w g(w) \le c_2$ 意味着 gradient 也是有界的 (小于一个值)
  • $\sum_{k=1}^\infty a_k = \infty$ and $\sum_{k=1}^\infty a_k^2 < \infty$
    • $\sum_{k=1}^\infty a_k = \infty$ 确保 $a_k$ 不会快速收敛到 0 (如果很早就到 0 了, 那么加起来就不可能是无穷)
    • $\sum_{k=1}^\infty a_k^2 < \infty$ 确保在 $k \rightarrow \infty$ 时 $a_k$ 收敛到 0
  • $E[\eta_k | H_k] = 0$ and $E[\eta_k^2 | H_k] < \infty$
    • $E[\eta_k | H_k] = 0$ 期望为 0
    • $E[\eta_k^2 | H_k] < \infty$ variance 为 0

$\sum_{k=1}^\infty a_k^2 < \infty$ 这个条件的重要性体现为 $w_k$ 最终会收敛:

$$
\displaylines
{
\begin{aligned}
w_{k+1} - w_k = -a_k \overset{\sim}{g}(w_k, \eta_k)
\end{aligned}
}
$$

  • 当 $a_k \rightarrow 0$ 时, 有 $a_k \overset{\sim}{g}(w_k, \eta_k) \rightarrow 0$, 即 $w_{k+1} - w_k \rightarrow 0$, 意味着继续迭代也不会有太多变动 (会收敛)

$\sum_{k=1}^\infty a_k = \infty$ 的重要性体现为 $w_1$ 不管取什么都能找到 $w^*$. 我们将 $w_2 = w_1 - a_1 \overset{\sim}{g}(w_1, \eta_1)$, $w_3 = w_2 - a_2 \overset{\sim}{g}(w_2, \eta_2)$, …, $w_{k+1} = w_k - a_k \overset{\sim}{g}(w_k, \eta_k)$ 这些加起来, 得到:

$$
\displaylines
{
\begin{aligned}
w_\infty - w_1 = \sum_{k=1}^\infty a_k \overset{\sim}{g}(w_k, \eta_k)
\end{aligned}
}
$$

  • $w_\infty$ 就是 $w_*$, 而 $w_1$ 是猜测的值
  • 右侧可能是无限的, 意味着就算 $w_1$ 选取得离 $w^*$ 很远, 也能找到

$a_k$ 通常取 $\frac{1}{k}$, 因为有两个结论:

  • Euler-Mascheroni constant, $k \approx 0.577$

$$
\displaylines
{
\begin{aligned}
\lim_{n \rightarrow \infty} (\sum_{k=1}^n \frac{1}{k} - \ln n) = k
\end{aligned}
}
$$

  • Basel problem

$$
\displaylines
{
\begin{aligned}
\sum_{k=1}^\infty \frac{1}{k^2} = \frac{\pi^2}{6} < \infty
\end{aligned}
}
$$

很多时候也会直接取 $a_k$ 为一个很小的常数, 而非 $\frac{1}{k}$ (越往后分母越大, 导致数据不起作用).

Stochastic gradient descent

Stochastic gradient descent (SGD) 的目标是解决下面优化问题:

$$
\displaylines
{
\begin{aligned}
\min_w J(w) = E[f(w, X)]
\end{aligned}
}
$$

有三种常用方法解决上面问题, 其思路都是递进的.

第一个是 gradient descent (当最小化一个目标时考虑梯度下降, 最大化一个目标时考虑梯度上升), $w_k$ 是我们对 $w^*$ 的估计, $w_{k+1}$ 是我们对 $w_k$ 的改进:

$$
\displaylines
{
\begin{aligned}
w_{k+1} = w_k - \alpha_k \nabla_w E[f(w_k, X)] = w_k - \alpha_k E[\nabla_w f(w_k, X)]
\end{aligned}
}
$$

  • $\nabla_w E[f(w_k, X)]$ 是函数 $E[f(w_k, X)]$ 的梯度
  • $\alpha_k$ 是步长, 用来控制沿着梯度下降的速度快慢
  • $\nabla_w$ 也可以放在 $E$ 内部

该方法的问题之前也提到过, 直接计算全样本的数学期望 (或高维积分) 在计算上是极其昂贵甚至不可能的, 且现实场景中, 数据的真实概率分布是未知的.

第二种方法是 batch gradient descent (BGD), 核心思想就是, 将期望转换为采样样本的平均:

$$
\displaylines
{
\begin{aligned}
E[\nabla_w f(w_k, X)] \approx \frac{1}{n} \sum_{i=1}^n \nabla_w f(w_k, x_i) \newline \newline
w_{k+1} = w_k - \alpha_k \frac{1}{n} \sum_{i=1}^n \nabla_w f(w_k, x_i)
\end{aligned}
}
$$

类似蒙特卡洛, 用数据来估算. 但如果批次大小 $n$ 很大, 每一步的计算开销依然很昂贵. 而如果使用固定大小的批次和固定步长, 算法在接近最优解时会在周围剧烈震荡, 无法精确收敛. 比如 $n = 256$, 固定步长 $\alpha$, 当算法刚开始离最优解很远时, 能快速前进, 但在算法走到最优解附近时, 由于每次会抽取 n 个样本, 总会带来随机偏差 (样本均值不等于真实期望), 此时这个固定的梯度估计会带着参数在最优解附近不停震荡无法收敛.

为了打破僵局, 引入了第三种方法 stochastic gradient descent (SGD), 其直接把批次大小缩减到 1, 其完美对应了之前提到的 stochastic approximation, 每次只随机抽取一个样本 $x_k$:

$$
\displaylines
{
\begin{aligned}
w_{k+1} = w_k - \alpha_k \nabla_w f(w_k, x_k)
\end{aligned}
}
$$

对比 gradient descent, 把全样本的数学期望梯度替换为了单个随机样本的梯度.

对比 batch gradient descent, 将批次大小 (batch size) 缩减到 1, 每次只挑一个样本, 将时间复杂度从 $O(n)$ 降到了 $O(1)$.

SGD 把单个样本的梯度 $\nabla_w f (w_k, x_k)$ 直接当成真实梯度的无偏估计, 在结合递减步长后, 能够以极小的总计算成本收敛.

这里需要理解一下无偏估计 (unbiased estimator). 在统计学中, 如果我们想估计一个未知的真实值 (比如全班的平均身高 $\mu$), 但我们无法统计所有人, 只能随机抽一个人 $x_k$. 如果这个抽样过程是公平的, 意味着虽然单次抽出来的人可能偏高或偏矮, 但在概率的宏观视角下, 抽样结果的平均值正好等于真实平均值, 我们就称这个估计是无偏的.

$$
\displaylines
{
\begin{aligned}
E[\hat{\theta}] = \theta
\end{aligned}
}
$$

  • $\hat{\theta}$ 是构造的随机变量
  • $\theta$ 是一个真实值
  • 一句话来说就是用估计值的期望来近似真实值

用在这里, 我们需要用估计值 $\nabla_w f(w_k, x_k)$ 的期望 $E[\nabla_w f(w_k, x_k)]$ 来近似真实值 $\nabla f_(w_k)$. 而我们不知道全部样本, 也没法直接求期望, 于是用之前的迭代算法来求:

$$
\displaylines
{
\begin{aligned}
w_{k+1} = w_k - \alpha_k \nabla_w f(w_k, x_k)
\end{aligned}
}
$$

也就是说, 这里的 $w_k$ 就是估计值的期望, 也是我们想要得到的真实值.

Example

比如需要最小化 $J(w)$:

$$
\displaylines
{
\begin{aligned}
\min_w J(w) = E[f(w, X)] = E[\frac{1}{2} || w - X ||^2]
\end{aligned}
}
$$

where

$$
\displaylines
{
\begin{aligned}
f(w, X) = || w - X ||^2, \nabla_w f(w, X) = w - X
\end{aligned}
}
$$

我们要求最小值, 其实就是找 $\nabla_w J(w) = 0$ 的点 (此时不会往更低的地方走了).

下面都是求这个梯度的方法.

这个梯度可以用估计值梯度的期望来求, 即 $E[\nabla_w f(w, X)]$, 因此有: $E[\nabla_w f(w, X)] = 0$, 即 $E[w - X] = 0$. 由于 w 不是随机变量, 其期望就是它自己, 因此有 $w - E[X] = 0$, 即 $w = E[X]$.

如果用 gradient decent 来求这个梯度 (用迭代求估计值的期望, 也就是目标梯度), 就有:

$$
\displaylines
{
\begin{aligned}
w_{k+1} &= w_k - \alpha_k \nabla_w J(w_k) \newline \newline
&= w_k - \alpha_k E[\nabla_w f(w_k, X)] \newline \newline
&= w_k - \alpha_k E[w_k - X]
\end{aligned}
}
$$

如果用 SGD 求解, 写法为:

$$
\displaylines
{
\begin{aligned}
w_{k+1} &= w_k - \alpha_k \nabla_w f(w_k, x_k) = w_k - \alpha_k (w_k - x_k)
\end{aligned}
}
$$

这个式子和 mean estimation algorithm 相同, 因此也可以说: mean estimation algorithm 是 SGD algorithm 的一种特殊情况.

Convergence

这里说明 SGD 的收敛性

从 GD 到 SGD, 有:

$$
\displaylines
{
\begin{aligned}
w_{k+1} &= w_k - \alpha_k E [\nabla_w f(w_k, X)] \newline \newline
&\Downarrow \newline \newline
w_{k+1} &= w_k - \alpha_k \nabla_w f(w_k, x_k)
\end{aligned}
}
$$

可以把:

  • $E[\nabla_w f(w, X)]$ 视作是 true gradient
  • $\nabla_w f(w_k, x_k)$ 视作是 stochastic gradient

有:

$$
\displaylines
{
\begin{aligned}
\nabla_w f(w_k, x_k) = E[\nabla_w f(w, X)] + \underbrace{\nabla_w f(w_k, x_k) - E[\nabla_w f(w, X)]}_\eta
\end{aligned}
}
$$

也就是 stochastic gradient 等于 true gradient 加上一个 error.

这样看 stochastic gradient 是不会精确等于 true gradient 的, 但可以证明 SGD 能够在 $k \rightarrow \infty$ 时, 得到 $w_k \rightarrow w^*$.

这里分析的核心, 就是证明 SGD 是一种特殊的 RM algorithm (RM 算法在满足一定条件后能收敛, 如果证明成功, 也就能说明 SGD 收敛).

SGD 的目标是最小化下面方程:

$$
\displaylines
{
\begin{aligned}
J(w) = E[f(w, X)]
\end{aligned}
}
$$

可以将该问题转化为一个 root-finding problem (求根问题):

$$
\displaylines
{
\begin{aligned}
\nabla_w J(w) = E[\nabla_w f(w, X)] = 0
\end{aligned}
}
$$

令:

$$
\displaylines
{
\begin{aligned}
g(w) = \nabla_w J(w) = E[\nabla_w f(w, X)]
\end{aligned}
}
$$

那么 SGD 的目标就转换为求解 $g(w) = 0$ 的根.

虽然 $g(w)$ 的精确表达是我们不知道, 但我们可以通过数据得到测量值 $\overset{\sim}{g} (w, \eta)$:

$$
\displaylines
{
\begin{aligned}
\overset{\sim}{g} (w, \eta) &= \nabla_w f(w, x) \newline \newline
&= \underbrace{E[\nabla_w f(w, X)]}_{g(w)} + \underbrace{\nabla_w f(w, x) - E[\nabla_w f(w, X)]}_\eta
\end{aligned}
}
$$

如果用 RM algorithm 来求解就有:

$$
\displaylines
{
\begin{aligned}
w_{k+1} = w_k - a_k \overset{\sim}{g} (w_k, \eta_k) = w_k - a_k \nabla_w f(w_k, x_k)
\end{aligned}
}
$$
中间是 RM algorithm, 右侧是 SGD, 两者相等就得到证明 (其实就是把 $\overset{\sim}{g} 拆开)$.

(说实在的没太懂, 公式都知道是什么意思了, 但感觉就像是自己证明自己一样)

Convergence pattern

SGD 本质就是将 GD 中 true gradient 的部分用 stochastic gradient 来代替. 由于 stochastic gradient 具有随机性, 就需要考虑是否 SGD 收敛的过程也有较大随机性 (比如绕了很大圈子才到 $w^*)$, 以及收敛到的结果是否有很大随机性.

Stochastic gradient 和 true gradient 之间的 relative error 表示如下:

$$
\displaylines
{
\begin{aligned}
\delta_k = \frac{| \nabla_w f(w_k, x_k) - E[\nabla_w f(w_k, X)] |}{E[\nabla_w f(w_k, X)]}
\end{aligned}
}
$$

  • 分子是 stochastic gradient 减去 true gradient
  • 分母是 true gradient

对于 $w^*$ 而言, $\nabla_w f(w^*, X)$ 是 0 (梯度为 0 表示找到极值, 这里也是最优解), 因此 $E[\nabla_w f(w^*, X)] = 0$ (0 的期望也是 0), 可以把它加到分母中, 便于后续推导:

$$
\displaylines
{
\begin{aligned}
\delta_k = \frac{| \nabla_w f(w_k, x_k) - E[\nabla_w f(w_k, X)] |}{E[\nabla_w f(w_k, X)] - E[\nabla_w f(w^*, X)]}
\end{aligned}
}
$$

由 mean value theorem ($f(x_1) - f(x_2) = f’(x_3) (x_1 - x_2)$, 这个其实我不太懂), 可以得到:
$$
\displaylines
{
\begin{aligned}
\delta_k &= \frac{| \nabla_w f(w_k, x_k) - E[\nabla_w f(w_k, X)] |}{E[\nabla_w f(w_k, X)] - E[\nabla_w f(w^*, X)]} \newline \newline
&= \frac{| \nabla_w f(w_k, x_k) - E[\nabla_w f(w_k, X)] |}{E[\nabla^2_w f(\overset{\sim}{w_k}, X)(w_k - w^*)]}
\end{aligned}
}
$$

其中 $\overset{\sim}{w_k} \in [w_k, w^*]$.

假设 f 是 strictly convex 的, 就有:

$$
\displaylines
{
\begin{aligned}
\nabla^2_w f \ge c > 0
\end{aligned}
}
$$

之后 $\delta_k$ 的分母就可以写为:

$$
\displaylines
{
\begin{aligned}
|E[\nabla^2_w f(\overset{\sim}{w_k}, X) (w_k - w^*)]| &= |E[\nabla^2_w f(\overset{\sim}{w_k}, X)]\ (w_k - w^*)| (把 w_k - w^* 移出 expectation 计算)
&= |E[\nabla_w^2 f(\overset{\sim}{w_k}, X)]|\ |(w_k - w^*)| \ge c |w_k - w^*|
\end{aligned}
}
$$

带回 $\delta_k$ 就能得到不等式:

$$
\displaylines
{
\begin{aligned}
\delta_k \le \frac{ | \overbrace{\nabla_w f(w_k, x_k)}^{stochastic\ gradient} - \overbrace{E[\nabla_w f(w_k, X)]}^{true\ gradient} |}{\underbrace{c |w_k - w^*|}_{distance\ to\ the\ optimal\ solution}}
\end{aligned}
}
$$

从这个式子可以看出:

  • 当 $w_k$ 离 $w^*$ 比较远时, $|w_k - w^*|$ 很大, 因此 relative error 就很小. 此时 SGD 的行为就和 GD 类似
  • 当 $w_k$ 离 $w^*$ 比较近时, 会体现出随机性

Deterministic formulation

前面讲的 SGD 的公式都是包含 random variables 和 expectation 的, 但在有些场景下并没有随机变量, 因此需要一个 deterministic formulation of SGD.

比如下面优化问题:

$$
\displaylines
{
\begin{aligned}
\min_w J(w) = \frac{1}{n} \sum_{i=1}^n f(w, x_i)
\end{aligned}
}
$$

  • $f(w, x_i)$ 是一个 parameterized function
  • $w$ 是需要优化的参数
  • $\{x_i\}_{i=1}^n$ 是一系列 real numbers, $x_i$ 并不是从 random variable 中采样得到的

用 gradient descent algorithm 求解:

$$
\displaylines
{
\begin{aligned}
w_{k+1} = w_k - \alpha_k \nabla_w J(w_k) = w_k - \alpha_k \frac{1}{n} \sum_{i=1}^n \nabla_w f(w_k, x_i)
\end{aligned}
}
$$

假设 $\{x_i\}_{i=1}^n$ 很大, 每次只取一个 number, 因此可以得到:

$$
\displaylines
{
\begin{aligned}
w_{k+1} = w_k - \alpha_k \nabla_w f(w_k, x_i)
\end{aligned}
}
$$

这个式子看起来与 SGD 非常相似, 但缺少随机变量. 这里可以手动定义一个 random variable X, 前面说从 $\{x_i\}_{i=1}^n$ 中取一个 number, 现在就按照 random variable 的概率分布来取, 这里用 uniform distribution:

$$
\displaylines
{
\begin{aligned}
p(X = x_i) = \frac{1}{n}
\end{aligned}
}
$$

此时优化目标就可以改写为:

$$
\displaylines
{
\begin{aligned}
\min_w J(w) = \frac{1}{n} \sum_{i=1}^n f(w, x_i) = E[f(w, X)]
\end{aligned}
}
$$

求解该问题的算法也就能转换为 SGD 了.

BGD, MBGD, and SGD

这里研究的问题同样是, 给定一组 random sample $\{x_i\}_{i=1}^n$:

$$
\displaylines
{
\begin{aligned}
\min_w J(w) = E[f(w, X)]
\end{aligned}
}
$$

用 BGD, SGD, MBGD 分别求解, 有:

$$
\displaylines
{
\begin{aligned}
w_{k+1} = w_k - \alpha_k \frac{1}{n} \sum_{i=1}^n \nabla_w f(w_k, x_i),\ \ (BGD) \newline \newline
w_{k+1} = w_k - \alpha_k \frac{1}{m} \sum_{j \in I_k}^n \nabla_w f(w_k, x_j),\ \ (MBGD) \newline \newline
w_{k+1} = w_k - \alpha_k \nabla_w f(w_k, x_k),\ \ (SGD) \newline \newline
\end{aligned}
}
$$

  • BGD 每次迭代都需要用到所有的采样 (用来求平均)
  • MBGD 每次迭代用一部分采样 (这个集合称 $I_k$)
  • SGD 只随机采样一个

MBGD 相比于 SGD 随机性更低, 因为选取了一部分样本做平均. 当 m=1 时, MBGD 就变成了 SGD; 但当 m=n 时, MBGD 严格上来说不是 BGD, 因为 MBGD 是随机抽取 n 个 (可能重复), 而不是取全部 n 个样本.

Summary

Chapter 7: Temporal-Difference Learning

Temporal-Difference Learning, 时序差分学习, 是强化学习中一个非常经典的 model-free incremental 方法. 之前介绍的 Monte Carlo Learning 也是 model-free 的, 但它是 non-incremental 的方法.

视频引入时用到了下面含 noisy 的 $g(w)$ 的式子, 一开始没看懂, 因此这里需要解释一下:

$$
\displaylines
{
\begin{aligned}
\overset{\sim}{g} (w_k, \eta_k) = w - x = (w - E[x]) + (E[X] - x) = g(w) + \eta
\end{aligned}
}
$$

这个式子其实从右边往左边看比较容易理解:

  • $\overset{\sim}{g} (w_k, \eta_k)$ 是 $g(w)$ 加上 noisy $\eta$
  • $g(w)$ 的定义是 $w - E[x]$, 而 $\eta$ 的定义是 $E[X] - x$
  • 两者相加能抵消掉 $E[X]$

这个 $\overset{\sim}{g}$ 是无偏的. 即 $E[\overset{\sim}{g}]$ 是 $g(w)$ 的无偏估计:

$$
\displaylines
{
\begin{aligned}
E[\overset{\sim}{g}] &= g(w) \newline \newline
E[g(w) + \eta] &= g(w) \newline \newline
g(w) + E[\eta] &= g(w)
\end{aligned}
}
$$

意思是需要证明 $\eta$ 的期望为 0.

试着求一下 $\eta$ 的期望:
$$
\displaylines
{
\begin{aligned}
E[\eta] = E[E[X] - x]
\end{aligned}
}
$$

因为 $E[X]$ 是一个常量, 因此可以提出来:

$$
\displaylines
{
\begin{aligned}
E[E[X] - x] = E[X] - E[x]
\end{aligned}
}
$$

在概率论中, 随机变量 $E[x]$ 的期望就是 $E[X]$, 所以:

$$
\displaylines
{
\begin{aligned}
E[E[X] - x] = E[X] - E[X] = 0
\end{aligned}
}
$$

噪声 $\eta$ 的数学期望为 0, 证明了单样本梯度虽然看起来有偏差, 但从长远期望来看, 是无偏的.

视频课引入 TD 算法之前, 用 RM 算法解了 3 个问题, 流程都是一样的:

  1. 定义 $g(w)$ 将原问题转换为求根 (最小化/最大化这类优化问题就是找极值, 本质就是求梯度为 0 的点, 也是求根)
  2. 定义 $\overset{\sim}{g}$ 引入 noisy observation
  3. 将 $\overset{\sim}{g}$ 带入 RM 算法求解中

第一个问题是简化期望的计算: $w = E[X]$, 即求 $X$ 的期望. 直接求 $E[X]$ 需要先找到所有样本点, 而这里试图找到一个 $w$ 能直接得到期望.

我们定义:

$$
\displaylines
{
\begin{aligned}
g(w) = w - E[X]
\end{aligned}
}
$$

这样当 $g(w) = 0$ 时, 就有 $0 = w - E[X], w = E[X]$. 即找到一个 $w$ 使得 $g(w) = 0$, 相当于就得到了 $w = E[X]$.

由于存在随机变量, $g(w)$ 需要引入误差 $\eta = E[X] - x$, 因此有:

$$
\displaylines
{
\begin{aligned}
\overset{\sim}{g} (w, \eta) = g(w) + \eta = (w - E[X]) + (E[X] - x) = w - x
\end{aligned}
}
$$

带入 RM 迭代算法:

$$
\displaylines
{
\begin{aligned}
w_{k+1} = w_k - \alpha_k \overset{\sim}{g} (w_k, \eta_k) = w_k - \alpha_k (w_k - x_k)
\end{aligned}
}
$$

  • $w_k$ 是第 k 次迭代对期望的估计值
  • $w_{k+1}$ 是新的期望估计值
  • $\alpha_k \overset{\sim}{g} (w_k, \eta_k)$ 是一个修正值

第二个问题是求解 $w = E[v(X)]$, 即求 $v(X)$ (随机变量的函数) 的期望.

同样先定义 $g(w)$:

$$
\displaylines
{
\begin{aligned}
g(w) = w - E[v(X)]
\end{aligned}
}
$$

再引入 noisy:
$$
\displaylines
{
\begin{aligned}
\overset{\sim}{g} (w, \eta) = g(w) + \eta = (w - E[v(X)]) + (E[v(X)] - v(x)) = w - v(x)
\end{aligned}
}
$$

再带入 RM 算法:

$$
\displaylines
{
\begin{aligned}
w_{k+1} = w_k - \alpha_k \overset{\sim}{g} (w_k, \eta_k) = w_k - \alpha_k (w_k - v(x_k))
\end{aligned}
}
$$

第三个问题是求 $w = E[R + \gamma v(X)]$, 即 $R + \gamma v(X)$ 的期望 (两个随机变量).

同样先定义 $g(w)$:

$$
\displaylines
{
\begin{aligned}
g(w) = w - E[R + \gamma v(X)]
\end{aligned}
}
$$

再引入 noisy:

$$
\displaylines
{
\begin{aligned}
\overset{\sim}{g} (w, \eta) &= g(w) + \eta \newline \newline
&= (w - E[R + \gamma v(X)]) + (E[R + \gamma v(X)] - [r + \gamma v(x)]) \newline \newline
&= w - [r + \gamma v(x)]
\end{aligned}
}
$$

再带入 RM 算法:

$$
\displaylines
{
\begin{aligned}
w_{k+1} = w_k - \alpha_k \overset{\sim}{g} (w_k, \eta_k) = w_k - \alpha_k (w_k - [r + \gamma v(x)])
\end{aligned}
}
$$

这个式子和后续会讲的 TD 算法已经很相似了, 可以把 $R$ 视作是 Reward, $\gamma$ 视作是 discount rate, $X$ 视作是 state value.

TD learning of state values

TD learning 是基于 data/experience 的, 由给定 policy $\pi$ 产生的 数据通常可以写为 $(s_0, r_1, s_1, …, s_t, r_{t+1}, s_{t+1}, …)$ 或者 ${(s_t, r_{t+1}, s_{t+1})}$.

TD learning 可以根据这些数据来求出 $\pi$ 的 state value (这里直接给出公式, 本质还是迭代和修正的思路):

$$
\displaylines
{
\begin{aligned}
v_{t+1} (s_t) &= v_t (s_t) - \alpha_t (s_t) [ v_t (s_t) - [ r_{t+1} + \gamma v_t (s_{t+1}) ] ] \newline \newline
v_{t+1} (s) &= v_t (s), \forall s \ne s_t
\end{aligned}
}
$$

  • 这里的 $s$ 是 state space 里任意一个状态
  • $v(s)$ 是对 $v_\pi (s)$ 的近似
  • $v_t (s_t)$ 是在 t 时刻 (第 t 次迭代) 的 state value 估计值
  • $r_{t+1} + \gamma v_t(s_{t+1})$ 来自 bellman equation, 是利用 $s_t$ 采样得到的即时奖励 $r_{t+1}$ 和下一步的 return $v_t(s_{t+1})$, TD 算法的目的就是用它们来估计当前 state value, 因此向它们靠近

第一个式子, 表示在 $t$ 时刻, 对 $v_t (s_t)$ 进行更新, 然后得到 $v_{t+1} (s_t)$.

第二个式子, 表示除了 $s_t$ (正在访问的那个状态) 以外, 其他状态的 state value 保持不变.

这里为第一个式子做一些标注:

这里的 $[r_{t+1} + \gamma v_t (s_{t+1})]$ 是 TD target $\overline{v}_t$, 意思是 $v_t (s_t)$ 想要向其靠近. 而 $v_t (s_t)$ 与这个 target 之间的距离, 就是 error.

我们用 $\overline{v}_t$ 这个符号来表示 target.

这个算法就是让 $v(s_t)$ 向 $\overline{v}_t$ 靠近. 下面是一个证明:

$v_{t+1} (s_t)$ 比 $v_t(s_t)$ 离 $\overline{v}_t$ 更近.

还需要看一下 TD error 的式子:

$$
\displaylines
{
\begin{aligned}
\delta_t = v(s_t) - [r_{t+1} + \gamma v(s_{t+1})]
\end{aligned}
}
$$

注意这里有 $t$ 和 $t+1$ 两个时刻. 其还反映了 $v_t$ (当前估计值) 与 $v_\pi$ (想要估计的值) 之间的差异. 当 $v_t$ 等于 $v_\pi$ 时, 这个差值就该为 0 (不需要再变化了, 也没有误差了). 下面证明为什么为 0.

先将 $v$ 换成 $v_\pi$:

$$
\displaylines
{
\begin{aligned}
\delta_{\pi, t} = v_\pi (s_t) - [r_{t+1} + \gamma v_\pi (s_{t+1})]
\end{aligned}
}
$$

虽然 $v_\pi(s_t)$ 是一个确定值, 但是 $r_{t+1}$ 和 $s_{t+1}$ 是随机变量, 因此一个确定值减去随机变量算出来的还是随机变量, 不能保证每次采样都为 0 (我们需要让 $\delta_t = 0$, 但此时 $\delta_{\pi, t}$ 由于随机性没法为 0). 因此考虑取 $\delta_{\pi, t}$ 的 expectation, 如果 expectation 为 0, 说明长远来看确实是让 $v_t$ 靠近了 $v_\pi$:

$$
\displaylines
{
\begin{aligned}
E[\delta_{\pi, t} | S_t = s_t] = v_\pi (s_t) - E[R_{t+1} + \gamma v_\pi (S_{t+1}) | S_t = s_t] = 0
\end{aligned}
}
$$

因为根据 Bellman equation, 有 (即时奖励加上下一个 state 的 value):

$$
\displaylines
{
\begin{aligned}
v_\pi (s_t) = E[R_{t+1} + \gamma v_\pi (S_{t+1}) | S_t = s_t]
\end{aligned}
}
$$

注意这里介绍的 TD algorithm 只能用来估计 state value of a given policy, 而不能估计 action value 和 optimal policies.

convergence and comparison

TD 算法在数学上就是在没有模型的情况下求解给定策略 $\pi$ 的 Bellman equation.

这里需要引入 bellman equation 的一个新形式.

首先 state value of $\pi$ 定义为:

$$
\displaylines
{
\begin{aligned}
v_\pi (s) = E[R + \gamma G | S = s], s \in S
\end{aligned}
}
$$

  • $R$ 是 reward 的随机变量
  • $\gamma$ 是 discount rate
  • $G$ 是下一个 state 的 state value 的随机变量
  • $S = s$ 表示当前状态是 $s$

我们可以先写出 $G$ 的 expectation:

$$
\displaylines
{
\begin{aligned}
E[G|S=s] = \sum_a \pi (a|s) \sum_s’ p(s’ | s, a) v_\pi (s’) = E[v_\pi (S’) | S = s]
\end{aligned}
}
$$

  • 求 expectation 就是加权平均, 这里每一个可能的下一个 state 的 state value 是 $v_\pi (s’)$, 对应的权值是 $\sum_a \pi (a|s) \sum_s’ p(s’ | s, a)$
  • $E[G|S=s]$ 和 $E[v_pi(S’) | S=s]$ 是等价的写法, 应该不需要推导也能得到

将上式带回新 bellman equation 得到:

$$
\displaylines
{
\begin{aligned}
v_\pi (s) = E[R + \gamma v_\pi (S’) | S = s], s \in S
\end{aligned}
}
$$

这个式子称为 bellman expectation equation. 是后续设计和分析 TD algorithms 的重要工具.

接下来需要求解这个 bellman equation, 即定义一个 $g(w)$, 当 $w = w^*$ 时, 有 $v(s) - E[R + \gamma v_\pi (S’) | s] = 0$, 即 $v(s) = E[R + \gamma v_\pi (S’) | s]$:

$$
\displaylines
{
\begin{aligned}
g(v(s)) = v(s) - E[R + \gamma v_\pi (S’) | S = s], s \in S
\end{aligned}
}
$$

  • 这里的 $v(s)$ 是 $v_\pi (s)$ 的估计值

目标是得到:

$$
\displaylines
{
\begin{aligned}
g(v(s)) = 0
\end{aligned}
}
$$

写出包含 noisy 的 $\overset{\sim}{g} (v(s))$ 有:

$$
\displaylines
{
\begin{aligned}
\overset{\sim}{g} (v(s)) &= g(v(s)) + \eta \newline \newline
&= v(s) - E[R + \gamma v_\pi (S’) | s] + E[R + \gamma v_\pi (S’) | s] - [r + \gamma v_\pi (s’)] \newline \newline
&= v(s) - [r + \gamma v_\pi (s’)]
\end{aligned}
}
$$

最后带入 RM algorithm 求解:

$$
\displaylines
{
\begin{aligned}
v_{k+1} (s) &= v_k (s) - \alpha_k \overset{\sim}{g} (v_k (s)) \newline \newline
&= v_k (s) - \alpha_k (v_k (s) - [r_k + \gamma v_\pi (s’_k)]), k = 1, 2, 3, …
\end{aligned}
}
$$

注意这里为了计算 $v_{k+1} (s)$, 用到了 $v_\pi (s’_k)$ 这个真实值, 而真实值我们是不知道的. 因此需要做一次替换, 将其也改为估计值 $v_k (s’_k)$. 在替换之后, 收敛性仍然是成立的:

TD learning of action values: Sarsa

这里同样没有模型, 但我们有数据 (experience) $\{(s_t, a_t, r_{t+1}, s_{t+1}, a_{t+1})\}_t$. 目的是求 given policy $\pi$ 的 action value.

Sarsa algorithm 的公式如下:

$$
\displaylines
{
\begin{aligned}
q_{t+1} (s_t, a_t) &= q_t(s_t, a_t) - a_t (s_t, a_t) [ q_t(s_t, a_t) - [r_{t+1} + \gamma q_t (s_{t+1}, a_{t+1})] ], \newline \newline
q_{t+1} (s, a) &= q_t (s, a), \forall (s, a) \ne (s_t, a_t) \newline \newline
\end{aligned}
}
$$
where $t = 0, 1, 2, …$

  • $q_t (s_t, a_t)$ 是 $q_\pi (s_t, a_t)$ 的估计值
  • $\alpha_t (s_t, a_t)$ 是由 $s_t,a_t$ 决定的 learning rate

这和之前介绍的 TD algorithm 是一样的, 只不过:

  • 将 $v(S_t)$ 替换为了 $q(S_t, a_t)$
  • 之前是用状态 $\{S\}$ 求 $v_\pi (S)$, 现在则是用 $\{(S,a)\}$ 求 $q_\pi (S,a)$

Sarsa 是 state-action-reward-state-action 首字母的缩写, 来源自其使用的 experience $s_t, a_t, r_{t+1}, s_{t+1}, s_{t+1}$.

Sarsa 的本质也是求解 bellman equation, 只是在这里的形式是:

$$
\displaylines
{
\begin{aligned}
q_\pi (s, a) = E[R + \gamma q_\pi (S’, A’) | s, a], \forall s, a.
\end{aligned}
}
$$

  • 先生成 experience
  • 进行 policy evaluation, 更新 q-value

  • 让所有 state 都找到最优策略

TD learning of action values: Expected Sarsa 和 n-step Sarsa

Expected Sarsa 的公式如下:

$$
\displaylines
{
\begin{aligned}
q_{t+1} (s_t, a_t) &= q_t (s_t, a_t) - \alpha_t (s_t, a_t) [ q_t (s_t, a_t) - (r_{t+1} + \gamma E[q_t (s_{t+1}, A)]) ], \newline \newline
q_{t+1} (s,a) = q_t (s, a), \forall (s, a) \ne (s_t, a_t)
\end{aligned}
}
$$

where:

$$
\displaylines
{
\begin{aligned}
E[q_t (s_{t+1}, A)] = \sum_a \pi_t (a | s_{t+1}) q_t (s_{t+1}, a) = v_t (s_{t+1})
\end{aligned}
}
$$

  • 唯一的区别就是把 $q_t (s_{t+1}, a_{t+1})$ (这是 action value) 替换为了 $E[q_t (s_{t+1}, A)]$ (这算出来是一个 state value)
  • 也就是改变了 TD target, 由于要计算 expectation, 计算量会增加. 由于直接从 $A$ 采样, 因此不需要 $a_{t+1}$, 此时的 experience 变为 $\{s_t, a_t, r_{t+1}, s_{t+1}\}$

这里也是求解一个 bellman equation:

$$
\displaylines
{
\begin{aligned}
q_\pi (s,a) = E[R_{t+1} + \gamma v_\pi (S_{t+1}) | S_t = s, A_t = a]
\end{aligned}
}
$$

n-step Sarsa 是 Sarsa 的一种推广.

先回顾一下 action value 的定义:
$$
\displaylines
{
\begin{aligned}
q_\pi(s, a) = E[G_t | S_t = s, A_t = a].
\end{aligned}
}
$$

这里的 $G_t$ 可以有多种定义:

需要注意这里 $G_t = G_t^{(1)} = G_t^{(2)} = G_t^{(n)} = G_t^{(\infty)}$, 区别只在如何分解.

Sarsa 的目标是求解:

$$
\displaylines
{
\begin{aligned}
q_\pi (s,a) = E[G_t^{(1)} | s, a] = E[R_{t+1} + \gamma q_\pi (S_{t+1}, A_{t+1}) | s, a].
\end{aligned}
}
$$

MC learning 的目标是求解:
$$
\displaylines
{
\begin{aligned}
q_\pi (s,a) = E[G_t^{(\infty)} | s, a] = E[R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + … | s, a].
\end{aligned}
}
$$

而 n-step Sarsa 则是两者的折中, 目标是求解:

$$
\displaylines
{
\begin{aligned}
q_\pi (s,a) = E[G_t^{(n)} | s, a] = E[R_{t+1} + \gamma R_{t+2} + … + \gamma^n q_\pi(S_{t+n}, A_{t+n}) | s, a].
\end{aligned}
}
$$

算法公式如下:

$$
\displaylines
{
\begin{aligned}
q_{t+1} (s_t, a_t) = q_t (s_t, a_t) - \alpha_t (s_t, a_t) [q_t (s_t, a_t) - [r_{t+1} + \gamma r_{t+2} + … + \gamma^n q_t (s_{t+n}, a_{t+n})]].
\end{aligned}
}
$$

与 Sarsa 和 expected Sarsa 的区别同样在 TD target.

当 $n = \infty$, $\alpha_t = 1$, 就能变为 MC learning.

n-step Sarsa 需要的 experience 格式为 $(s_t, a_t, r_{t+1}, s_{t+1}, a_{t+1}, …, r_{t+n}, s_{t+n}, a_{t+n})$. 由于在 $t$ 时刻还没有得到 $(r_{t+n}, s_{t+n}, a_{t+n})$, 因此没法进行更新, 需要等待运行直到 $t + n$, 之后从后往前更新:

$$
\displaylines
{
\begin{aligned}
q_{t+n} (s_t, a_t) = q_{t+n-1} (s_t, a_t) - \alpha_{t+n-1} (s_t, a_t) [q_{t+n-1} (s_t, a_t) - [r_{t+1} + \gamma r_{t+2} + … + \gamma^n q_{t+n-1} (s_{t+n}, a_{t+n})]].
\end{aligned}
}
$$

由于 Sarsa 和 MC learning 就是 n-step Sarsa 的两种 extreme cases, 因此其性质也是两者的混合:

  • 当 $n$ 很大时, 性质接近 MC learning
  • 当 $n$ 很小时, 性质接近 Sarsa

TD learning of optimal action values: Q-learning

Q-learning 能直接估计 optimal action value, 因此不需要 policy evaluation 和 policy improvement 两个步骤交替运行

其公式如下:

$$
\displaylines
{
\begin{aligned}
q_{t+1} (s_t, a_t) = q_t (s_t, a_t) - \alpha_t (s_t, a_t) [q_t (s_t, a_t) - [r_{t+1} + \gamma \max_{a \in A} q_t (s_{t+1}, a)]], \newline \newline
q_{t+1} (s,a) = q_t (s,a), \forall (s,a) \ne (s_t,a_t),
\end{aligned}
}
$$

从结构上来讲与 Sarsa 是一样的, 只有 TD target 不同:

  • Sarsa 是 $r_{t+1} + \gamma q_t(s_{t+1}, a_{t+1})$
  • Q-learning 是 $r_{t+1} + \gamma max_{a \in A} q_t (s_{t+1}, a)$

之前的 Sarsa 是求解 bellman equation, 而这里的 Q-learning 求解的是 bellman optimality equation:

$$
\displaylines
{
\begin{aligned}
q(s,a) = E[R_{t+1} + \gamma \max_a q(S_{t+1}, a) | S_t = s, A_t = a], \forall s,a.
\end{aligned}
}
$$

TD learning task 中通常涉及两种 policies:

当它们不同时, 就是 off-policy (比如 Q-learning, 其既可以让 behavior policy 和 target policy 相同, 也可以让其不同).

可以从两个方面来判断一个 RL algorithm 是 on-policy 还是 off-policy:

  • 从 algorithm 的数学形式上分析
  • 检查 algorithm 的实现需要哪些组件

比如考虑下面一个例子:

假如 state 非常多, 非常密集, 此时如果还是用 tabular 的方法, 就需要很大的存储空间来保存 state 和 state value 的对应关系.

而如果用一个函数来拟合, 则只需要保存两个参数:

$$
\displaylines
{
\begin{aligned}
\hat(v) (s,w) = a s + b &= \underbrace{[s, 1]}_{\phi^T (s)} \underbrace{\begin{bmatrix} a \newline \newline b \end{bmatrix}}_w \newline \newline
&= \phi^T (s) w
\end{aligned}
}
$$

  • $w$ 是 parameter vector
  • $\phi (s)$ 是 feature vector
  • $\hat{v} (s, w)$ 是 w 的一个线性函数

此时只需要存储 $a$ 和 $b$ 两个参数.

当然还可以用更高维度的曲线来拟合, 代价就是存储更多参数, 比如:

$$
\displaylines
{
\begin{aligned}
\hat(v) (s,w) = a s^2 + b s + c \newline \newline
&= \underbrace{[s^2, s, 1]}_{\phi^T (s)}
\underbrace{\begin{bmatrix} a \newline \newline b \newline \newline c \end{bmatrix}}_w \newline \newline
&= \phi^T (s) w
\end{aligned}
}
$$

需要注意, $\hat{v} (s, w)$ 是 $s$ 的 nonlinear 函数, 但对 $w$ 还是 linear 函数.

Value function approximation 的核心思想就是, 用 $\hat{v} (s, w)$ 来拟合 $v_\pi (s)$ (多了参数 $w \in R^m$). 优点就是减少存储, 以及增加泛化性. 在 tabular 的方法中, 如果想更新一个 state 的 state value, 就必须访问该 state, 而在 function approximation 中, 只要访问了一个 state, 整个 function 就会发生一些变化, 这会导致其他 state 的 state value 对应关系也会更新, 即泛化能力更强.

Foundation - objective function

我们的目标是找到一个 optimal $w$, 使得 $\hat{v} (s, w)$ 尽可能接近 $v_\pi (s)$.

Objective function 定义如下:

$$
\displaylines
{
\begin{aligned}
J(w) = E[(v_\pi (S) - \hat{v} (S, w))^2]
\end{aligned}
}
$$

  • $v_\pi (S)$ 是真值
  • $\hat{v} (S, w)$ 是估计值
  • $v_\pi (S) - \hat{v} (S, w)$ 是误差
  • 目标是最小化 $J(w)$, 即最小化误差

这里的 $S$ 是一个随机变量, 我们需要得知其概率分布, 才能算 expectation.

如果假设 $S$ 是 uniform distribution, 意思是将所有 states 视为同等重要 (equally important), 每个 state 出现的概率是 $\frac{1}{|S|}$. 此时 objective function 就变为:

$$
\displaylines
{
\begin{aligned}
J(w) &= E[(v_\pi (S) - \hat{v} (S, w))^2] \newline \newline
&= \frac{1}{|S|} \sum_{s \in S} (v_\pi (s) - \hat{v} (s, w))^2
\end{aligned}
}
$$

这种假设的坏处是, states 并不是 equally important 的.

第二种则假设 $S$ 是 stationary distribution (状态的概率分布, 也可以视为状态的权重, 也称为 steady-state distribution 或 limiting distribution), 其描述了一个 Markov process 的 long-run behavior (这个不太懂, 可能要查一下). 用 $\{d_\pi (s)\}_{s \in S}$ 来表示在 policy $\pi$ 下, 一个 Markov process 的 stationary distribution, 满足:

$$
\displaylines
{
\begin{aligned}
d_\pi (s) \ge 0 \newline \newline
\sum_{s \in S} d_\pi (s) = 1
\end{aligned}
}
$$

即概率大于 0, 概率总和为 1.

此时 objective function 可以改写为:

$$
\displaylines
{
\begin{aligned}
J(w) &= E[(v_\pi (S) - \hat{v} (S, w))^2] \newline \newline
&= \sum_{s \in S} d_\pi (s) (v_\pi (s) - \hat{v} (s, w))^2
\end{aligned}
}
$$

Stationary distribution 可以用一些 episode 来得到, 比如近似为:

$$
\displaylines
{
\begin{aligned}
d_\pi (s) \approx \frac{n_\pi (s)}{\sum_{s’ \in S} n_\pi (s’)}
\end{aligned}
}
$$

  • 分母 $\sum_{s’ \in S} n_\pi (s’)$ 是 episode 中所有状态被访问的总次数
  • 分子 $n_\pi (s)$ 表示状态 $s$ 在 episode 中被访问的次数

Long-run 就是指当 episode 足够长时, stationary distribution 中各 state 的权重会趋于平稳.

通常我们也不需要用长 episode 来算 $d_\pi^T$, 可以借助 $p(s’ | s)$ 状态转移函数:

$$
\displaylines
{
\begin{aligned}
d_\pi^T = d_\pi^T P_\pi
\end{aligned}
}
$$

这里的 $P_\pi$ 就是 bellman equation 中的那个: $v_\pi = r_\pi + \gamma P_\pi v_\pi$.

简单来说, stationary distribution 就是每个 state 被访问的概率, 可以用状态转移的 distribution 计算得到.

Foundation - optimization algorithm and function selection

比如用 gradient-descent algorithm 来优化该 objective function $J(w)$, 有:

$$
\displaylines
{
\begin{aligned}
w_{k+1} = w_k - \alpha_k \nabla_w J(w_k)
\end{aligned}
}
$$

这里的 $\nabla_w J(w_k)$ 是 true gradient, 展开如下:

$$
\displaylines
{
\begin{aligned}
\nabla_w J(w) &= \nabla_w E[(v_\pi (S) - \hat{v} (S, w))^2] \newline \newline
&= E [\nabla_w (v_\pi (S) - \hat{v} (S,w))^2] \newline \newline
&= 2E[(v_\pi (S) - \hat{v}(S, w))(-\nabla_w \hat{v} (S, w))] \newline \newline
&= -2E[(v_\pi (S) - \hat{v}(S, w))(\nabla_w \hat{v} (S, w))]
\end{aligned}
}
$$

由于这里要求 expectation 会比较困难, 可以考虑用 stochastic gradient 来代替这里的 true gradient:

$$
\displaylines
{
\begin{aligned}
w_{t+1} = w_t + \alpha_t (v_\pi (s_t) - \hat{v} (s_t, w_t)) \nabla_w \hat{v} (s_t, w_t)
\end{aligned}
}
$$

需要注意这里的 $v_\pi (s_t)$ 是真实值, 我们得不到, 因此需要用某种方式替换.

可以选择用 Monte Carlo learning 替换这部分, 此时公式变为:

$$
\displaylines
{
\begin{aligned}
w_{t+1} = w_t + \alpha_t (g_t - \hat{v} (s_t, w_t)) \nabla_w \hat{v} (s_t, w_t)
\end{aligned}
}
$$

这里的 $g_t$ 是从 $s_t$ 出发, 整个 episode 的 discounted return.

另一种方法是用 TD learning:

$$
\displaylines

\begin{aligned}
w_{t+1} = w_t + \alpha_t [r_{t+1} + \gamma \hat{v} (s_{t+1}, w_t) - \hat{v} (s_t, w_t)] \nabla_w \hat{v} (s_t, w_t)
\end{aligned}
}
$$

这里的 linear case 是指, 当 $\hat{v} (s,w) = \phi (s)$ 时, 有:

$$
\displaylines
{
\begin{aligned}
\nabla_t \hat{v} (s, w) = \phi (s)
\end{aligned}
}
$$

将其替换到 TD algorithm 中就有:

$$
\displaylines
{
\begin{aligned}
w_{t+1} = w_t + \alpha_t [r_{t+1} + \gamma \hat{v} (s_{t+1}, w_t) - \hat{v}(s_t, w_t)] \nabla_w \hat{v} (s_t, w_t) \newline \newline
w_{t+1} = w_t + \alpha_t [r_{t+1} + \gamma \phi^T (s_{t+1}) w_t - \phi^T(s_t) w_t] \phi (s_t)
\end{aligned}
}
$$

这种 linear function approximation 的缺点是: 很难选取合适的 feature vectors. 好处则是: 容易分析其 theoretical properties.

Tabular representation 其实是 linear function approximation 的一种特殊形式.

假设 feature vector 为:

$$
\displaylines
{
\begin{aligned}
\phi (s) = e_s \in R^{|S|}
\end{aligned}
}
$$

这里的 $e_s$ 是一个向量, 且只在 $s$ 位置为 1, 其余位置为 0.

有:

$$
\displaylines
{
\begin{aligned}
\hat{v} (s, w) = e^T_s w = w(s)
\end{aligned}
}
$$

其中 $w(s)$ 是 sth entry of w.

在 TD-linear algorithm 中:

$$
\displaylines
{
\begin{aligned}
w_{t+1} = w_t + \alpha_t [r_{t+1} + \gamma \phi^T (s_{t+1}) w_t - \phi^T(s_t) w_t] \phi (s_t)
\end{aligned}
}
$$

把 $\phi (s_t) = e_s$ 替换进去:

$$
\displaylines
{
\begin{aligned}
w_{t+1} = w_t + \alpha_t [r_{t+1} + \gamma \phi^T (s_{t+1}) w_t - w_t (s_t)] e_{s_t}
\end{aligned}
}
$$

两边同时乘以 $e_{s_t}^T$ 就有:

$$
\displaylines
{
\begin{aligned}
w_{t+1} (s_t) = w_t (s_t) + \alpha_t (r_{t+1} + \gamma w_t (s_{t+1}) - w_t (s_t))
\end{aligned}
}
$$

这里提两个 objective function, 后续有精力再分析:

  • bellman error

$$
\displaylines
{
\begin{aligned}
J_{BE} (w) = || \hat{v} (w) - (r_\pi + \gamma P_\pi \hat{v} (w)) ||^2_D = || \hat{v} (w) - T_\pi (\hat{v} (w)) ||^2_D
\end{aligned}
}
$$

  • projected bellman error

$$
\displaylines
{
\begin{aligned}
J_{PBE} (w) = || \hat{v} (w) - MT_\pi (\hat{v} (w)) ||_D^2
\end{aligned}
}
$$
这里的 $M$ 是 projection matrix, 做一些修正使得 error 接近 0.

Deep Q-learning - basic idea

Deep Q-learning 也可以叫做 deep Q-network (DQN), 是最早也是最成功将 deep neural networks 引入 RL 的一个算法之一.

Neural networks 在这里用作 nonlinear function approximator.

Deep Q-learning 要最小化的 objective function (loss function) 如下:

$$
\displaylines
{
\begin{aligned}
J(w) = E[(R + \gamma \max_{a \in A(S’)} \hat{q} (S’, a, w) - \hat{q} (S, A, w))^2]
\end{aligned}
}
$$

这里的 $(S, A, R, S’)$ 都是 random variables.

其本质是 bellman optimality error:

$$
\displaylines
{
\begin{aligned}
q(s,a) = E[R_{t+1} + \gamma \max_{a \in A(S_{t+1})} q(S_{t+1}, a) | S_t = s, A_t = a], \forall s,a
\end{aligned}
}
$$

可以尝试用 Gradient descent 来最小化这个 objective function.

首先需要求 $J(w)$ 的梯度:

$$
\displaylines
{
\begin{aligned}
J(w) = E[(R + \gamma \max_{a \in A(S’)} \hat{q} (S’, a, w) - \hat{q} (S, A, w))^2]
\end{aligned}
}
$$

这里有两个地方含有 $w$, 直接求梯度并不容易. 一个思路是, 把:

$$
\displaylines
{
\begin{aligned}
y = R + \gamma \max_{a \in A(S’)} \hat{q} (S’, a, w)
\end{aligned}
}
$$

这部分的 $w$ 视为常数, 只用 $\hat{q} (S, A, w)$ 来计算梯度.

为了实现该技巧, 需要引入 two networks:

  • 一个是 main network $\hat{q} (s, a, w)$ (每进入一个样本则更新 $w$)
  • 另一个是 target network $\hat{q} (s, a, w_T)$ (每隔一段时间复制 $w_T = w$)

此时得到:

$$
\displaylines
{
\begin{aligned}
J = E[(R + \gamma \max_{a \in A(S’)} \hat{q} (S’, a, w_T) - \hat{q} (S, A, w))^2]
\end{aligned}
}
$$

当 $w_T$ 固定为一个常量时, J 的 gradient 可以计算为:

$$
\displaylines
{
\begin{aligned}
\nabla_w J = E[(R + \gamma \max_{a \in A(S’)} \hat{q} (S’, a, w_T) - \hat{q} (S, A, w)) \nabla_w \hat{q} (S, A, w)]
\end{aligned}
}
$$

Deep Q-learning - Experience replay

在收集 experience samples 时, 会有先后顺序, 比如先产生和后产生. 但是使用 experience 时, 并不会依赖这个顺序. 我们会把所有 experience sample 放到一个集合中, 称作 replay buffer $B = \{(s, a, r, s’)\}$. 训练时会从这个 buffer 中取 batch 数据, 这个取数据的过程则是 experience replay (通常会根据 uniform distribution 来取, 为什么要用 uniform distribution 视频课感觉没讲清楚).
